## 6. 核心发现与建议

1. **标题格式不一致**：存在「第 X 条」「第 X、Y、Z 条」「第五十条」「第 X 天」等多种格式，解析条文编号时需兼容顿号分隔、中文数字、无"条"字等变体。
2. **三文件可通过 `note_id` 关联**：
   - `notes_catalog.json` → 元数据与标题
   - `notes_ocr.json` → 原始 OCR 文本
   - `伤寒论条文_小红书针道轩.md` → 清洗后的条文与解析
3. **第 101–200 条为全覆盖黄金区间**：该区间 100 条条文全部通过多条文笔记（通常每篇 3 条）覆盖，数据完整性最高。
4. **疑似缺失条文**：第 51–56、78–100、246、282、287、293、300、303、305 条未在标题中直接出现，建议抽查 `covers/` 中对应笔记的图片内容，确认是否已采集但标题未标注。
5. **早期笔记价值**：编号为 0 的 102 条笔记虽无明确条文编号，但包含「这样学/背《伤寒论》」系列（含胡希恕解析），适合作为「学习方法论」卡片素材。
