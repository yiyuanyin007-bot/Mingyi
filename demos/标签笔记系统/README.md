# DEMO：标签 + 笔记系统

## 设计对齐

- **目标**：验证「以笔记为主」的标签体系交互是否直观——标签的添加/批量粘贴/删除/检索流程是否顺畅
- **用户场景**：陈医生在经方学习过程中，阅读条文时记笔记，给笔记打标签，后续通过标签检索笔记
- **核心交互**：输入标签 → 回车添加 → 标签显示在笔记上（多对多）→ 搜索框输入关键词→跨标题/内容/标签检索
- **数据需求**：Mock 数据（4 条预设笔记，涵盖桂枝汤、麻黄汤、小柴胡汤）
- **不做什么**：不实现与卡片的关联存储、不实现掌握度联动、不实现服务端持久化

## 设计合约

| 条目 | 决定 |
|------|------|
| 标签作用对象 | 笔记（不是卡片） |
| 标签-笔记关系 | 多对多（一条笔记可打多个标签） |
| 标签添加方式 | 输入框 + 回车添加；支持批量粘贴（逗号/空格/换行分隔） |
| 标签删除方式 | 点击标签上的 ✕ 按钮删除 |
| 标签检索入口 | 统一在搜索栏——输入关键词匹配标题/内容/标签 |
| 笔记 Markdown | 支持渲染（粗体、代码块、列表、引用、表格） |
| 长文本处理 | >200 字默认折叠，点击展开 |
| 笔记入口 | 条文面板 + 独立笔记列表页（本 DEMO 展示后者） |
| 笔记+标签存储 | 独立于卡片数据，存在 localStorage |

## 交互流程

1. 用户看到双栏布局：左侧笔记列表，右侧详情/编辑区
2. 点击左侧笔记 → 右侧显示完整内容和标签
3. 在标签输入框输入文字 → 按回车 → 标签即刻添加
4. 点击「批量粘贴」→ 粘贴多个标签（如"太阳病, 表虚证, 自己心得"）→ 确认 → 全部识别
5. 点击标签上的 ✕ → 删除标签
6. 在搜索框输入关键词 → 左侧列表实时过滤（匹配标题、内容、标签）
7. 编辑笔记内容 → 右侧实时 Markdown 预览 → 点击保存或 Ctrl+Enter
8. 长文本显示折叠按钮 → 点击展开/收起
