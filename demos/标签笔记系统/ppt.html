经方笔记系统 · 设计总纲 第一性原理推导 → 五条设计原则

核心问题：笔记系统服务于什么学习动作？
→ 「信息 → 理解 → 应用」的转化过程中，笔记是唯一贯穿的接口。
  1. 一个笔记模型：不分类型，只分来源。所有笔记同一存储、同一 Schema、同一检索。
  2. 入口即标签（核心标签自动打）：从哪个场景进入记笔记，系统自动打上对应核心标签，零操作完成分类。
  3. 浮窗记笔记：原地弹出，不跳转页面，不丢失上下文。打断成本最低。
  4. 临时标签用户自定：用户按个人学习目的追加标签，系统不干预。
  5. 康奈尔对比产出链接笔记：两篇笔记并排 + 底部产出区（手动 / AI 生成对比总结），产出「链接笔记」——一种专门记录"两个知识点之间关系"的新品种。
核心标签 系统自动，标识来源 临时标签 用户手动，个人分类

浮窗交互规则
• 浮窗是轻量 modal，不跳转页面，不覆盖主内容区超过 60%
• 标题 / 核心标签 / 关联条文（或错题）自动预填，用户无需手动关联
• 内容区支持 Markdown，底部标签输入框支持回车添加 / 批量粘贴
• 保存后 toast 提示「笔记已保存」，浮窗自动关闭
• 再次点击记笔记，浮窗底部显示「已有笔记列表」，可快速翻阅

标签体系 核心标签 vs 临时标签 · 新增 #链接笔记

核心标签
由系统自动打上，标识这条笔记从哪个学习场景产生。用户不可删除，不可修改。
作用：保证每条笔记天然带有分类属性，无需用户思考。
临时标签
由用户手动添加，按个人学习目的自由组织。
作用：让你的笔记体系适应你的个性化学习路径——比如标记「易混淆」「刘渡舟经验」「我的盲区」「要背」。

对比视图 — 康奈尔布局 两篇并排 + 底部产出区 =「链接笔记」

认知原理：对比的真正价值不在「并排看见」，而在「并排之后你产出了什么」。
左右两栏展示原版笔记（只读），底部横条是你的对比产出区——自己写、或点 Kimi 生成对比总结后粘贴进来。
保存后成为一条独立的新笔记品种：#链接笔记
操作路径：笔记列表页 → 勾选 2 条 → 🔍 对比 → 进入此布局
🥇 桂枝汤 — 太阳中风证 #条文
病机：营卫不和，表虚
症状：发热、汗出、恶风、脉浮缓
脉象：浮缓（阳浮阴弱）
汗出：有汗（自汗出）
方药：桂枝 芍药 生姜 大枣 甘草
禁忌：酒客、内热者不宜
🥈 麻黄汤 — 太阳伤寒证 #方剂笔记
病机：卫阳被遏，营阴郁滞，表实
症状：恶寒发热、无汗、身痛、腰痛
脉象：浮紧
汗出：无汗
方药：麻黄 桂枝 杏仁 甘草
禁忌：表虚自汗、疮家、淋家
✍️ 对比总结产出 #链接笔记 桂枝汤 麻黄汤 鉴别 表证
核心鉴别点：有汗 vs 无汗——这是表虚和表实的根本分界。
桂枝汤证脉浮缓（阳浮阴弱），麻黄汤证脉浮紧。
临床关键问诊：出汗吗？怕风还是怕冷？
✏️ 自己写 🤖 Kimi 生成对比 💾 保存为链接笔记
康奈尔对比规则
• 左右两栏：只读展示原版笔记（各自可独立滚动）
• 底部横条：你的对比产出，支持 Markdown。可手动写，也可点 Kimi 生成后粘贴
• 底部标签：自动继承两篇笔记的所有标签（核心+临时），去重合并。用户可追加
• 保存后：产生一条 source.type="link_note" 的新笔记，linkFrom 记录关联的笔记 ID
• 从笔记列表点击链接笔记 → 自动进入此康奈尔布局，重新加载关联的两篇笔记
