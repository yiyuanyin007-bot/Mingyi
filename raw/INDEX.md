## 数据流向

```
raw/
├── annotations/ ──→ extracted/annotations/（标注提取）
│                      └→ data/（结构化到 JSON 卡片）
├── classical/ ────→ scripts/parse_shanghanlun.py（条文解析）
│                      └→ data/（结构化到源文章卡片）
├── annotations-chm/（12 个 .chm）
│   └→ raw/extracted-chm/（HTML 提取，工具如 chmdump/htmlhelp）
│       └→ extracted/（知识提取管线）
│           ├→ source_cards/（源文章卡片化）
│           ├→ formula_elements/（方剂要素提取）
│           └→ experiences/（经验知识提取）
└── archive/ ─────→ （归档，不参与活跃管线）
```

**处理优先级**: 当前主力数据源是 `extracted-chm/` → `extracted/` → `data/` 管线。`annotations/` 和 `classical/` 为老数据源。
