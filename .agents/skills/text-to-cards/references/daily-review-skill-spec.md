# daily-review Skill 规范

> 从每日临床文件夹中读取录音转写和现场笔记，提取信息、配对患者、生成点评，最终输出「今天应该从哪些卡片开始学」的建议。

---

## 1. 触发条件

用户说类似以下的话时触发：

- "跑一下今天的文件夹"
- "生成今天的学习建议"
- "处理 2026-06-14 的录音和笔记"

---

## 2. 输入

### 2.1 必需输入

- 日期文件夹路径，例如：
  ```
  C:\Users\Chen\WorkBuddy\Claw\01-日常诊疗\2026-06-14
  ```

### 2.2 输入文件

| 文件类型 | 说明 |
|---------|------|
| `*_转写.txt` | 录音转写文本，按人或全局 |
| `*_现场笔记.pdf` | 手写现场笔记 |
| `*.md` | 其他 Markdown 笔记（排除输出文件） |

### 2.3 配置文件

可选：`config/formulas.txt`，定义当前已学习的方名清单。

---

## 3. 处理流程

```
读取文件夹内所有输入文件
  ↓
文本提取
  - 从转写中识别：患者主诉、脉象、舌象、选方、剂量、加减、临场感悟
  - 从 PDF 中识别：手写字段（初期只做 OCR 文本提取，不做结构化）
  ↓
患者配对
  - 按患者编号（P01、P02）把同一患者的录音和笔记合并
  - 全局录音作为未配对内容的补充
  ↓
逐诊点评
  - 这诊的重点是什么
  - 为什么这个选方/加减值得关注
  - 对系统有什么启示
  ↓
生成学习建议
  - 推荐卡片列表（按优先级排序）
  - 每张卡片建议从哪个向量开始
  - 是否需要新增经验卡
  ↓
写入输出文件
```

---

## 4. 提取字段

### 4.1 从转写/笔记中提取

| 字段 | 示例 | 用途 |
|------|------|------|
| `patient_id` | P01 | 患者配对 |
| `chief_complaint` | 汗出恶风三天 | 症状卡 |
| `pulse` | 浮缓 | 辨证依据 |
| `tongue` | 淡红苔薄白 | 辨证依据 |
| `selected_formula` | 桂枝汤 | 卡片关联 |
| `dosage_adjustment` | 桂枝加至四两 | 经验卡 |
| `additions_removals` | 加葛根 | lineage |
| `clinical_reflection` | 眼镜提示很有用 | 系统反馈 |
| `eyeglass_used` | 是/否 | 工具使用数据 |

### 4.2 不提取的内容

- 患者隐私信息（姓名、电话、地址）
- 与方剂学习无关的闲聊
- 重复冗余的口语填充词

---

## 5. 输出

### 5.1 输出文件

```
C:\Users\Chen\WorkBuddy\Claw\01-日常诊疗\2026-06-14\2026-06-14_学习建议.md
```

### 5.2 输出结构

```markdown
# 2026-06-14 学习建议

## 一、今日要点摘要

- 今日共看 X 位患者
- 使用方剂：桂枝汤、麻黄汤……
- 关键主题：汗出/无汗的鉴别、项背强痛的选方

## 二、逐诊点评

### 患者 P01

**重点**：汗出恶风，脉浮缓，用桂枝汤
**为什么重要**：典型桂枝汤证，适合做成标准学习案例
**系统启示**：桂枝汤的 `necessary` 症状可以强化

## 三、推荐卡片

### 高优先级

1. **桂枝汤**
   - 建议向量：方名→症状、症状→方名
   - 理由：今日出现多次，且症状典型
   - 是否新增经验卡：是（记录剂量调整细节）

2. **麻黄汤**
   - 建议向量：禁忌识别
   - 理由：今日遇到无汗患者，需要区分桂枝汤/麻黄汤

### 中优先级

3. **葛根汤**
   - 建议向量：方名→药物
   - 理由：药物组成较复杂，需要记忆

## 四、下一步行动

- [ ] 在 formula_cards.json 中更新桂枝汤的 symptom_profile
- [ ] 创建桂枝汤经验卡（P01 剂量调整）
- [ ] 不处理：全局录音中未识别内容，等待转写质量提升
```

---

## 6. 边界与限制

### 6.1 MVP 阶段不做

- 不自动从 `.m4a` 转录音频
- 不做语音识别或声纹分离
- 不自动生成/修改卡片 JSON（只出建议报告）
- 不做患者隐私脱敏之外的深度处理

### 6.2 需要人工确认

- 推荐卡片是否真的要创建
- 症状分类是否正确
- 经验卡的置信度级别

---

## 7. 运行方式

### 7.1 命令行

```powershell
python scripts/daily_review.py --date 2026-06-14 --folder "C:\Users\Chen\WorkBuddy\Claw\01-日常诊疗\2026-06-14"
```

### 7.2 对话触发

用户："跑一下今天的文件夹"

AI：
1. 询问或推断日期
2. 读取文件夹
3. 执行提取和生成
4. 返回 `2026-06-14_学习建议.md` 摘要

---

## 8. 与 text-to-cards 的关系

```
text-to-cards: 从典籍/注解文本中提取 source_card 和基础 formula_card
daily-review: 从临床实战中生成学习建议和经验卡候选

两者最终都输出到 data/ 目录，由前端原型读取。
```
