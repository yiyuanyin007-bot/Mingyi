# 卡片元素类型与判定规则

本文件定义 `text-to-cards` Skill 第一步能识别哪些元素，以及如何判定。

**当前版本为初版，规则简单，后续根据产出质量迭代。**

---

## 1. 元素类型总览

| 类型 | 字段目标 | 优先级 |
|------|---------|--------|
| `formula_name` | `formula_name` | 最高 |
| `source_text` | `data.source_text` | 高 |
| `symptom` | `data.symptoms` | 高 |
| `herb` | `data.herbs[].name` / `data.herbs[].dosage` | 高 |
| `usage` | `data.usage` | 中 |
| `contraindication` | `data.contraindications` | 中 |
| `pathology` | `data.pathology` | 中 |
| `experience` | `experiences[].content` | 低（暂以识别为主） |

---

## 2. 各元素判定规则

### 2.1 formula_name（方名）

**判定：** 句子中出现用户提供的范围清单里的方名。

**示例：**
- "太阳病，头痛，发热，汗出，恶风，**桂枝汤**主之。"
- "**麻黄汤**主之。"

**注意：** 范围清单必须预先给出，不能凭空识别方名。

---

### 2.2 source_text（原文条文）

**判定：** 句子包含方名，且句末有"主之"、"可与"、"宜"等结论词。

**示例：**
- "太阳病，头痛，发热，汗出，恶风，桂枝汤**主之**。"

**处理：** 整句作为 `data.source_text`。

---

### 2.3 symptom（症状）

**判定：** 句子中出现常见症状词，且该句子已关联到某个方名（同句或同段）。

**初版症状词库：**
```
头痛、头项强痛、项背强几几、发热、恶风、恶寒、汗出、无汗、喘、
胸胁苦满、默默不欲饮食、心烦、喜呕、往来寒热、谵语、潮热、
大便硬、绕脐痛、手足濈然汗出、骨节疼痛、身疼、腰痛、脉浮缓、脉浮紧
```

**示例：**
- "太阳病，**头痛**，**发热**，**汗出**，**恶风**，桂枝汤主之。"

**处理：** 每个症状作为一个独立元素。

**症状三分法（MVP 阶段人工标注，自动分类待后续实现）：**

| 类别 | 含义 | 上下文线索 | 示例 |
|------|------|-----------|------|
| `necessary` | 必要症 | 方名+"主之"、"必"、"者" | 桂枝汤：汗出、恶风 |
| `common` | 常见症 | 并列症状、无否定词 | 桂枝汤：头痛、发热 |
| `excluding` | 排除症 | "不可"、"不得"、"无...不可" | 桂枝汤：无汗、脉浮紧 |

MVP 阶段 `segment_text.py` 只识别症状词本身，不自动做三分法分类。分类在人工审阅或学习对话中完成。

---

### 2.4 herb（药物及剂量）

**判定：** 句子中出现已知药物名，且后面紧跟剂量词（两、升、枚、合、斤、两半等）。

**初版药物词库（伤寒论常见）：**
```
桂枝、芍药、甘草、生姜、大枣、麻黄、杏仁、葛根、大黄、厚朴、
枳实、芒硝、柴胡、黄芩、人参、半夏
```

**剂量词：**
```
两、斤、升、合、枚、个、片、方寸匕、分
```

**示例：**
- "**桂枝三两**、**芍药三两**、**甘草二两**"

**处理：** 拆成 `{name: "桂枝", dosage: "三两"}`。

---

### 2.5 usage（用法）

**判定：** 句子包含煎煮、服用、禁忌操作方法的关键词。

**关键词：**
```
以水、煮取、去滓、温服、日三服、分温再服、先煮、内诸药、
适寒温、服一升、啜粥、温覆、更上微火、得下
```

**示例：**
- "**以水七升，微火煮取三升，去滓，适寒温，服一升**。"

---

### 2.6 contraindication（禁忌）

**判定：** 句子包含否定词，且与某方相关。

**关键词：**
```
不可、不得、勿、忌、禁、反、非、无……不可
```

**示例：**
- "若脉浮紧，发热汗不出者，**不可**与也。"
- "**无汗**（用麻黄汤）"

---

### 2.7 pathology（病机）

**判定：** 句子解释病因、病机、病位。

**关键词：**
```
为、因、故、机、属、邪、正、营卫、气血、表里、寒热、虚实
```

**示例：**
- "**风邪袭表，营卫不和**"
- "**寒邪束表，营卫闭塞**"

**注意：** 病机句往往不直接含方名，需要结合同段上下文判断归属。

---

### 2.8 experience（经验/注释/医案）

**判定：** 句子明显是后人注释、医案记录、个人心得。

**关键词：**
```
云、曰、师、案、愚见、余临证、按、注、笔者认为
```

**示例：**
- "倪师**云**：桂枝汤为风伤卫之主方。"
- "**按**：此方……"

**处理：** 识别为经验卡候选，不直接写入方剂卡。

---

## 3. 分句规则

### 3.1 标准切分

以以下标点作为句子结束：
```
。 ； ？ ！
```

### 3.2 无标点长句

如果句子超过 80 字且无上述标点，尝试按语义切分：
- 按"若……"、"者……"等结构切分；
- 按并列症状列表切分（顿号、逗号分隔的短语）。

### 3.3 段落上下文保留

每个原子句都保留其所在段落的完整原文，作为 `paragraph_context`。
