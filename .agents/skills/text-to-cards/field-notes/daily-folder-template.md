# 每日临床文件夹模板

> 本模板定义每天实战结束后，录音、笔记、转写文件应该如何存放。
> 
> `daily-review` Skill 会读取这个文件夹，生成当天的学习建议。

---

## 文件夹路径

```
C:\Users\Chen\WorkBuddy\Claw\01-日常诊疗\YYYY-MM-DD\
```

例如：

```
C:\Users\Chen\WorkBuddy\Claw\01-日常诊疗\2026-06-14\
```

---

## 文件夹内容

```
2026-06-14/
├── 01-手机全局录音/
│   └── 2026-06-14_全局录音.m4a
│   └── 2026-06-14_全局录音_转写.txt        # 后续生成的转写
├── 02-平板按人录音/
│   ├── 2026-06-14_P01_患者1.m4a
│   ├── 2026-06-14_P01_患者1_转写.txt
│   ├── 2026-06-14_P02_患者2.m4a
│   └── 2026-06-14_P02_患者2_转写.txt
├── 03-现场笔记/
│   └── 2026-06-14_现场笔记.pdf              # 手写 PDF
├── 04-其他材料/
│   └── （照片、检查单等）
└── 2026-06-14_学习建议.md                    # 由 daily-review Skill 生成
```

---

## 文件命名规则

| 类型 | 命名格式 | 示例 |
|------|---------|------|
| 全局录音 | `YYYY-MM-DD_全局录音.m4a` | `2026-06-14_全局录音.m4a` |
| 按人录音 | `YYYY-MM-DD_PNN_备注.m4a` | `2026-06-14_P01_汗出恶风.m4a` |
| 转写文件 | 对应录音名 + `_转写.txt` | `2026-06-14_P01_汗出恶风_转写.txt` |
| 现场笔记 | `YYYY-MM-DD_现场笔记.pdf` | `2026-06-14_现场笔记.pdf` |
| 学习建议 | `YYYY-MM-DD_学习建议.md` | `2026-06-14_学习建议.md` |

**PNN** 中的 NN 是患者编号，从 01 开始。

---

## 对文件内容的最低要求

### 转写文件

- 能区分不同患者（按人录音自然区分，全局录音需要后续切分）
- 尽量保留口语中的关键信息：主诉、脉象、舌象、选方、剂量、临场感想

### 现场笔记 PDF

- 初期手写即可，不强制格式
- 但建议包含模板中的字段（见 `个人经验-李法师.md`）

---

## Skill 读取范围

`daily-review` Skill 会读取以下文件：

- `**/*_转写.txt`
- `**/*_现场笔记.pdf`
- `**/*.md`（排除 `_学习建议.md`）

不会读取原始 `.m4a` 音频文件（转写由其他工具完成）。
