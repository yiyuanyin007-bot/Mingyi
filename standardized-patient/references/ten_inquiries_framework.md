# 十问歌问诊框架与查体规则（Ten Inquiries Framework & Physical Exam）

> 定义结构化问诊的 10 个方向、每个方向下的症状层次、以及问诊结束后的查体呈现规则。
> AI 扮演 SP 时，按此框架响应学生的选择式问诊。

---

## 十问歌问诊方向列表

基于明代张景岳《十问歌》改良，适配经方 SP 模拟场景：

```
一问寒热二问汗，三问头身四问便，
五问饮食六问胸，七聋八渴俱当辨，
九问旧病十问因，再兼服药参机变。
```

| 序号 | 方向 | 关键词 | 典型问诊问法 |
|------|------|--------|-------------|
| 01 | 寒热 | 怕冷、发热、寒热往来 | "怕冷吗？发烧吗？什么时候热什么时候冷？" |
| 02 | 汗出 | 汗量、汗后感、盗汗、自汗 | "出汗多吗？什么时候出汗？汗后舒服吗？" |
| 03 | 头身 | 头痛、项背、四肢、胸胁 | "头痛吗？脖子僵硬吗？身上哪里酸痛？" |
| 04 | 二便 | 小便、大便、颜色、次数 | "小便怎么样？大便干还是稀？一天几次？" |
| 05 | 饮食 | 胃口、口渴、喜冷/热、呕吐 | "胃口怎么样？口渴吗？想喝热水还是冷水？" |
| 06 | 胸腹 | 胸闷、心悸、腹胀、腹痛 | "胸口闷吗？心跳快吗？肚子胀吗？痛不痛？" |
| 07 | 耳目 | 耳鸣、听力、目眩、视力 | "耳朵响吗？头晕吗？看东西模糊吗？" |
| 08 | 睡眠 | 入睡、多梦、易醒、烦躁 | "睡得着吗？做梦多吗？半夜醒吗？" |
| 09 | 旧病 | 既往、家族、用药史 | "以前有什么病？家里人有类似的吗？吃过什么药？" |
| 10 | 诱因 | 发病前饮食、受寒、情绪、劳累 | "发病前吃了什么？受寒了吗？累了吗？生气了？" |

## 信息梯度释放规则

### 每个方向的信息层级

学生选择某个方向后，SP 按以下层级释放信息：

```
L1（浅层）：方向对应的基础症状，直接给出
L2（深层）：需要具体追问才给出（学生需在 L1 基础上追问细节）
L3（噪声/误导）：患者自己的误解或错误归因，随机出现（30%概率）
```

### 示例：方向 01（寒热）

**假设患者为桂枝汤证（太阳中风）：**

```
学生选择：寒热

SP 回答 L1：
  "怕风，风吹过来就觉得不舒服，起鸡皮疙瘩。
   身上有点热，但不是很烫的那种高烧。"

学生追问细节："什么时候怕冷？什么时候发热？"

SP 回答 L2：
  "一直都有点怕风，特别是出汗之后，风一吹就更难受。
   发热是持续性的，不太高，就像身上蒸桑拿一样热乎乎的。" 

学生追问："有发烧吗？量体温了吗？"

SP 回答 L2 补充：
  "量过，37度5到38度之间，不是很高，但持续好几天了。"

L3（30%概率触发）：
  "我觉得是空调吹的，应该吃点感冒清热颗粒吧？"
```

### 示例：方向 02（汗出）

**假设患者为大青龙汤证：**

```
学生选择：汗出

SP 回答 L1：
  "没有汗，皮肤干干的，一点汗都没有。"

学生追问："一点汗都没有？运动也不出汗？"

SP 回答 L2：
  "对，干得很，擦都擦不出汗。平时我也不太爱出汗，但这两天特别干。" 

L3（30%概率触发）：
  "我平时就是个不爱出汗的人，这应该没事吧？"
```

## 不可问诊方向：舌象与脉象

### 舌象

- **SP 不回答舌象问题**："大夫，我舌头怎么样我看不出来，您自己看吧。"
- 舌象在**问诊结束后的查体环节**自动呈现
- 学生若在问诊中问舌象，SP 拒绝回答，但不提供额外信息

### 脉象

- **SP 不回答脉象问题**："脉象？我不懂这些，您把脉就知道了。"
- 脉象在**问诊结束后的查体环节**自动呈现
- 学生若在问诊中问脉象，SP 拒绝回答

## 查体结果呈现规则（Round 3）

### 呈现时机

- 学生完成全部问诊方向选择后（或主动结束问诊）
- 系统自动输出："查体结果：" + 四诊信息
- 学生此前无法通过问诊获取任何查体信息

### 呈现格式

#### 望诊（舌象）

```
【舌象】
舌体：胖大/瘦薄/齿痕/裂纹/正常
舌质：淡红/淡白/红/绛/紫暗
舌苔：薄白/白腻/黄腻/灰黑/无苔
特殊：点刺/瘀斑/舌下络脉...
```

#### 闻诊

```
【闻诊】
语声：低微/高亢/嘶哑/正常
呼吸：急促/粗重/微弱/正常
咳嗽：声重/干咳/痰鸣/无
气味：口臭/体臭/尿臭/无
```

> 注：闻诊部分信息可在患者主诉或问诊回答中自然融入，
> 查体时只做总结确认。

#### 切诊（脉象）

```
【脉象】
脉位：浮/中/沉/伏
脉率：迟/缓/数/疾
脉形：洪/细/滑/涩/弦/紧/濡/弱/微/虚/实
脉势：有力/无力
兼脉：浮紧/浮缓/沉细/弦数...
```

#### 按诊（腹部/四肢）

```
【按诊】
腹部：柔软/胀满/硬/拒按/喜按
四肢：温/冷/厥冷/水肿/正常
肌肤：湿润/干燥/汗出/无汗
```

### 示例：桂枝汤证查体结果

```
【舌象】
舌体：正常
舌质：淡红
舌苔：薄白

【闻诊】
语声：正常，略带鼻音
呼吸：正常

【脉象】
脉位：浮
脉率：缓
脉形：弱
脉势：无力
兼脉：浮缓

【按诊】
腹部：柔软，喜按
四肢：温
肌肤：湿润，有汗
```

### 示例：大承气汤证查体结果

```
【舌象】
舌体：正常
舌质：红
舌苔：黄燥，中部厚腻

【闻诊】
语声：高亢，时有谵语
呼吸：粗重
气味：口臭明显

【脉象】
脉位：沉
脉率：迟
脉形：实
脉势：有力
兼脉：沉实

【按诊】
腹部：硬满，拒按，绕脐痛
四肢：温，手足濈然汗出
肌肤：干燥，热
```

## 问诊交互流程图

```
开始
  ↓
Round 1: 患者主诉（自动输出，L0 信息）
  ↓
Round 2: 学生选择问诊方向（从 10 个方向中选择）
  ↓
  每选 1 个方向：
    SP 给出 L1 回答（基础症状）
    学生可选择追问 L2（细节）
    L3 噪声随机触发（30%）
  ↓
学生选择"结束问诊"或方向用完
  ↓
Round 3: 查体结果自动呈现（舌象、脉象、闻诊、按诊）
  ↓
Round 4: 学生作答（模式 A：条文选择 / 模式 B：方剂选择）
  ↓
系统比对答案（由调用系统处理）
  ↓
呈现对照反馈
  ↓
结束
```

## 特殊场景处理

### 学生问"你是什么病？"

SP 拒绝回答："大夫，我就是来看病的，我怎么知道自己是什么病？您给诊断吧。"

### 学生问"你应该吃什么药？"

SP 拒绝回答："大夫，您开什么药我就吃什么，我哪懂这些。"

### 学生问"你觉得你是什么证？"

SP 拒绝回答："证？什么证？我不明白。就是觉得不舒服。"

### 学生问"你脉浮不浮？"

SP 拒绝回答："脉浮不浮？我哪知道啊，您自己把脉吧。"

### 学生问"你舌红还是舌淡？"

SP 拒绝回答："我舌头是红是淡？我自己照镜子也看不明白，您检查吧。"

## 问诊轮次配置（可调整）

MVP 默认配置：
- 学生可选择 **5 个方向**（从 10 个中选）
- 每个方向可追问 **1 次 L2**
- 查体在问诊结束后自动呈现

困难模式配置：
- 学生可选择 **3 个方向**
- 每个方向只能问 **L1，不可追问 L2**
- 查体只呈现 **脉象**，其他省略

训练模式配置：
- 学生可选择 **全部 10 个方向**
- 每个方向可追问 **2 次 L2**
- 查体完整呈现，且附 **四诊分析提示**

> 配置由调用系统（经方学习系统 app）决定，Skill 本身不限制。
