# 症状口语化表达指南（Oral Expression Guide）

> 定义如何将中医症状术语转化为患者的自然口语表达。
> 模板化设计，便于后续为新增经典/方剂批量扩展。

---

## 表达原则

### 原则 1：术语剥离

患者不会使用以下词汇，必须转化：

| 禁用术语 | 患者可能说 |
|---------|-----------|
| 营卫不和 | "身体好像调不过来了，一会儿冷一会儿热" |
| 阳浮阴弱 | "身上发热，但又觉得虚，出完汗更虚" |
| 表虚 | "我抵抗力差，一吹风头就痛" |
| 里实 | "肚子硬邦邦的，大便出不来" |
| 脉浮缓 | "大夫，您把脉吧，我自己不知道" |
| 舌淡红 | "舌头颜色？我照镜子看不明白" |
| 蓄水 | "小便少，喝了水也不尿，肚子胀" |
| 瘀热 | "小肚子硬痛，按下去痛得厉害" |

### 原则 2：情绪嵌入

口语表达必须携带情绪色彩：

- **焦虑**："大夫，我这会不会是什么大病？好几天了也不见好。"
- **烦躁**："烦得很，坐不住，想发脾气。"
- **虚弱**："没力气，说话都觉得累，只想躺着。"
- **恐惧**："会不会很严重？我听说有人就这样..."
- **不耐烦**："看了好几个医生了，药吃了也不管用。"
- **自责**："都怪我前几天吃了凉的/吹了空调。"

### 原则 3：生活场景化

症状必须嵌入具体生活场景，而非孤立描述：

- 不是"汗出恶风"，而是"我昨天接孩子放学，风一吹，汗就下来了，当时就起鸡皮疙瘩"
- 不是"项背强几几"，而是"脖子后面僵僵的，像有什么扯住，转头都要慢慢转"
- 不是"腹满"，而是"肚子胀，按上去硬邦邦的，昨天晚上疼得睡不着"

### 原则 4：患者误解（L3 噪声）

30% 的病例包含患者自己的错误归因：

| 错误归因 | 示例 |
|---------|------|
| 归因于颈椎病 | "我觉得是颈椎病引起的脖子僵，之前拍片说有增生" |
| 归因于空调 | "肯定是空调吹的，我同事也这样" |
| 归因于饮食 | "吃了火锅就这样了，上火了" |
| 自我用药 | "我吃了感冒清热颗粒，不管用，又吃了布洛芬" |
| 网络诊断 | "我网上查了一下，像是流感，是不是要吃奥司他韦？" |
| 情绪归因 | "最近工作压力大，可能焦虑引起的" |

## 症状分类表达模板

### 一、寒热类

#### 发热

- 高热："烧得厉害，39度多，浑身烫"
- 中热："发烧，38度左右"
- 微热："有点低烧，37度5到38度"
- 翕翕发热："身上热乎乎的，像蒸桑拿，但不是很烫"
- 蒸蒸发热："身上热，像从里面往外蒸，觉得热得透不过气"
- 潮热："每天下午三四点开始发热，像定好了一样"
- 至夜发热："晚上发热，白天还好"
- 无大热："身上摸着不太烫，但心里觉得热"

#### 怕冷/恶风

- 恶寒："怕冷，盖两床被子还觉得冷"
- 恶风："怕风，风吹过来就觉得往骨头里钻，起鸡皮疙瘩"
- 啬啬恶寒："缩着怕冷，不敢伸出去"
- 微恶寒："有点怕冷，不是很严重"
- 背微恶寒："背上有点怕冷，其他地方还好"
- 时时恶风："有时候怕风，一阵一阵的"
- 不恶寒："不怕冷，还觉得热"

#### 寒热往来

- 往来寒热："一会儿热一会儿冷，像打摆子"
- 热多寒少："发热的时候多，怕冷的时候少"
- 寒多热少："怕冷的时候多，发热的时候少"
- 如疟状："像打摆子一样，但不是定时的"
- 一日二三度发："一天发作两三次，好像有规律"

## 症状组合叙事模板

### 模板：外感叙事

```
"我前几天 [诱因]，第二天就开始 [症状1]，
一开始以为是 [错误归因]，自己吃了 [自我用药]，
结果 [症状变化]，没办法才来看病。"

示例：
"我前几天吹空调受凉，第二天就开始发烧出汗，
一开始以为是普通感冒，自己吃了感冒清热颗粒，
结果烧没退，汗越出越多，还怕风，没办法才来看病。"
```

### 模板：误治叙事

```
"一开始 [症状1]，去 [就医场景] 看了，
大夫给我 [误治方式]，结果 [症状恶化]，
现在 [新症状]，比以前还难受。"

示例：
"一开始发烧头痛，去诊所看了，大夫给我吃了退烧药还打了点滴，
结果烧是退了，汗就止不住了，一直流，现在特别怕风，比以前还难受。"
```

### 模板：慢性病叙事

```
"我 [时间] 前就有 [旧病]，平时 [日常状态]，
这次 [诱因] 后，[症状群] 都加重了，
特别是 [核心症状]，[情绪描述]。"

示例：
"我半年前就容易感冒，平时抵抗力就差，
这次吹了冷风后，发烧、出汗、怕风都来了，
特别是汗出不停，大夫我这不会是什么大病吧？"
```

## 扩展方法

新增经典时，按以下步骤扩展表达库：

1. 从 `source_article_map.md` 读取新增条目的 `symptom_pool`
2. 对每个症状，从本指南中查找对应模板
3. 若症状为新症状（本指南未收录），按"术语剥离+情绪嵌入+生活场景化"三原则创建新表达
4. 将新表达追加到本指南末尾，并标注来源经典
5. 更新版本记录
