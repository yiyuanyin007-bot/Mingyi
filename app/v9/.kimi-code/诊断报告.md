## 根因定位

### 关键证据

通过对比**本地源码 app.js**（1155 行）与**线上 bundle main-DAJXTwVf.js**（279KB）：被 Vite Tree-Shaking 错误删除的代码：

| 关键函数/模块 | 本地源码 | 线上 bundle | 后果 |
|-------------|:-------:|:----------:|:----:|
| `async function init()` | ✅ | ❌ 被移除 | 应用永远不会初始化 |
| `switchView()` | ✅ | ❌ 被移除 | 页面路由瘫痪 |
| `subscribe()` | ✅ | ❌ 被移除 | Store 变化无法通知视图 |
| `setPage()` | ✅ | ❌ 被移除 | 无法通过 JS 切换页面 |
| `renderDashboard()` | ✅ | ❌ 被移除 | 统计面板无法动态更新 |
| `handleCardClick()` | ✅ | ❌ 被移除 | 点击卡片无法进入学习页 |
| `toggleTheme()` | ✅ | ❌ 被移除 | 主题切换失效 |
| `LearnView` 相关 | ✅ | ❌ 被移除 | 学习页不渲染 |
| `ExamService` | ✅ | ❌ 被移除 | 考试功能全无 |
| `SaveState` | ✅ | ❌ 被移除 | 学习进度无法保存 |
| `__APP_STORE_DEBUG__` | ✅ | ❌ 被移除 | 调试接口缺失 |
| `init()` **调用** | ✅ | ✅ 保留 | 调了一个不存在的函数，静默无效果 |

**`init()` 的函数定义被 tree-shaker 移除了，但 `init()` 的调用保留了下来**——这是异常行为。

### 可信根因分析

`rollupOptions.input` 配置只有 `index.html` 一个入口。Vite 构建流程：

1. `index.html` → 发现 `<script type="module" src="./src/app.js">`  
2. Rollup 解析 `./src/app.js` → 追踪所有 `import` 依赖  
3. Tree-shaking 分析 side-effect → **异常判断 `init()` 函数定义无副作用** → 删除定义  
4. 但 `init()` 调用本身被视为有副作用 → 保留调用（但这时 `init` 已不存在，执行了一个空表达式）

**直接修复方案（选一）：**

- **方案 A（推荐）**：在 `vite.config.js` 的 `rollupOptions` 中添加 `treeshake: false` 或设置 `moduleSideEffects` 标记
- **方案 B**：将 `init()` 改写为 IIFE（立即执行函数表达式），明确告知 Rollup 这是有 side-effect 的代码
- **方案 C**：在 `package.json` 中添加 `"sideEffects": true`

## 修复建议

### 最小修复（推荐，1次提交）

在 `vite.config.js` 中添加：

```js
build: {
  // ... existing config
  rollupOptions: {
    // ... existing input
  },
  // 禁用 tree-shaking 防止异常删除核心逻辑
  treeshake: false,
}
```

或者更精确的方式（保留 tree-shake 但保护 init）：

```js
// vite.config.js
export default defineConfig({
  // ... existing config
  build: {
    treeshake: {
      moduleSideEffects: (id) => {
        // 确保 src 目录下的所有模块被视为有副作用
        if (id.includes('/src/')) return true;
        return false;
      }
    }
  }
})
```

### 验证方式
```bash
cd app/v9
npm run build
# 检查 dist/assets/main-*.js 中是否包含 init、switchView、setPage 等函数
grep -l 'function init\|switchView\|setPage\|subscribe' dist/assets/*.js
```

然后部署到 Vercel：
```bash
npx vercel --prod ./dist
```
