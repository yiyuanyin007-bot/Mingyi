📚 经验与案例
1
大柴胡汤合三黄泻心汤治眩晕
形体壮实者眩晕频发，伴目赤、口苦、胃热，大柴胡汤合三黄泻心汤可清少阳郁热、泻心胃之火。
眩晕每于接触枕头时发作（体位性眩晕）
目睛充血、口唇疱疹、喜苦食 = 少阳郁热+胃热
形体壮实、腹部充实 = 大柴胡汤体质
📋 方子
柴胡12g，黄芩10g，制半夏10g，枳壳12g，白芍12g，制大黄6g，黄连3g，干姜5g，红枣20g
对应案例 眩晕频发案
37岁 · 女性 形体壮实 大柴胡汤合三黄泻心汤
眩晕目赤口唇疱疹胃烧灼喜苦食
眩晕频发，每于接触枕头时发作。目睛充血，口唇易疱疹，肩膀酸痛，烦躁心慌，胃中不适有烧灼感，左少腹按之疼痛，喜苦食。
处方同上方 → 药后舒适，诸症明显好转，眩晕仅秋天小有一次，头痛未作
2
大柴胡汤合桂枝茯苓丸治咳痰
老年形体充实者，肺纤维化伴咳痰不爽，大柴胡汤合桂枝茯苓丸可排痰化瘀、改善循环。
老年+形体充实+肺纤维化 = 痰瘀互结
脓痰咯出不爽、走路气喘 = 痰阻气机
下肢浮肿、时有抽筋 = 血瘀水停
📋 方子
柴胡6g，黄芩6g，制半夏6g，枳壳10g，赤芍10g，肉桂6g，桃仁6g，丹皮6g，茯苓12g，制大黄3g，干姜5g，红枣15g
对应案例 长期咳嗽咯痰不爽案
85岁 · 女性 形体充实 大柴胡汤合桂枝茯苓丸
咳嗽脓痰气喘口干苦下肢浮肿
形体充实，肺纤维化、风湿性关节炎、胆囊结石手术史。长期咳嗽，脓痰咯出不爽，走路后气喘，头背部僵痛，口干苦，腹胀，两腿乏力，下肢浮肿，时有抽筋。
处方同上方 → 药后一周咯痰即有好转，量减少而咯出转畅，口干好转，两腿较前有力，下肢浮肿轻微，大便通畅，睡眠可
3
大柴胡汤合方治过敏与寒证
肌肉结实者荤食寒冷过敏，大柴胡汤合桂枝茯苓丸、半夏厚朴汤可解少阳郁热、化饮除湿。
肌肉结实 = 大柴胡汤体质
不能吃荤食、皮肤过敏 = 湿热内蕴
头汗多、晨起喷嚏 = 水饮上逆
📋 方子
大柴胡汤合桂枝茯苓丸合半夏厚朴汤（具体剂量需根据患者调整）
对应案例 荤食寒冷过敏案
63岁 · 女性 肌肉结实 三方正合
皮肤过敏怕冷头汗喷嚏大便干
不能吃荤食及蒜、葱等，皮肤过敏。头部怕冷，头汗多，晨起打喷嚏、流鼻涕，咽喉不适，老有饥饿感，大便干，睡眠不佳。
大柴胡汤合桂枝茯苓丸合半夏厚朴汤 → 药后怕冷明显好转，已可穿短袖吹空调，饥饿感、晨起喷嚏、流鼻涕、鼻子不通好转，大便通畅，咽喉舒适
4
大柴胡汤合猪苓汤治关节痛伴水湿
强直性脊柱炎伴肾盂肾炎、下肢浮肿者，大柴胡汤合猪苓汤可清少阳湿热、利水消肿。
关节痛+下肢浮肿+尿频 = 湿热下注
夜尿多、易血尿 = 肾阴不足、热伤血络
体格充实、舌红 = 实热证
📋 方子
柴胡20g，黄芩20g，生甘草6g，黄柏6g，山栀10g，党参12g，制半夏12g，茯苓20g，猪苓20g，连翘40g，泽泻20g，干姜10g，红枣15g
对应案例 强直性脊柱炎肾盂肾炎案
56岁 · 女性 体格较充实 大柴胡汤合猪苓汤
关节痛下肢浮肿尿频血尿失眠
强直性脊柱炎20余年，全身关节不适，腰部酸重僵硬，下肢浮肿，尿频尿不尽，夜尿多，易有血尿，入睡困难。
处方同上方 → 药后关节疼痛缓解，小便次数减少，尿道刺激征不明显，下肢浮肿好转
5
大柴胡汤加黄连治三叉神经痛
中等偏实体型伴高血压、三叉神经痛者，大柴胡汤加黄连可清少阳郁热、泻火止痛。
三叉神经痛+高血压 = 肝阳上亢、少阳郁热
身热汗出、腹部充实 = 大柴胡汤证
经前乳胀、痛经 = 肝郁气滞
📋 方子
柴胡10g，黄芩15g，制半夏15g，枳壳15g，白芍15g，制大黄6g，黄连5g，干姜6g，红枣20g
对应案例 三叉神经痛案
49岁 · 女性 中等偏实 大柴胡汤加黄连
三叉神经痛高血压身热汗出经前乳胀便秘
三叉神经痛3月余，疼痛难忍需打止痛针，血压160/90mmHg。身热汗出，腹部按之充实，经前乳胀，痛经，大便偏干。
处方同上方 → 药后疼痛好转，身热汗出减少，一月后能喝冷果汁，头痛不显，偶尔牙根疼痛，大便畅
📜 条文讲解
条
伤寒论第165条
伤寒发热、汗出不解，心中痞硬、呕吐而下利者，大柴胡汤主之。
本条论述少阳阳明同病的证治
"心中痞硬"=少阳枢机不利，"呕吐而下利"=胆热犯胃、传导失常
