## 一、笔记原文摘要

### 核心辨证点
太阳中风表虚证，以汗出、恶风、脉浮缓为特征，病机为风邪袭表、营卫不和（卫强营弱）。

### 核心链条（原文）
> **外源性刺激（风邪/病原体）作用于体表 → 皮肤交感神经-汗腺轴功能紊乱 → 毛孔（汗腺导管）开阖失司，处于"开张不固"状态**

### 分章节症状群机制
- **汗出**：汗腺分泌亢进但调节失灵，蒸发散热过度
- **恶风**：外周血管扩张 + 持续蒸发散热 → 皮肤温度感受器对气流极度敏感
- **脉浮缓**：外周血管代偿性扩张（浮）；血管张力低、心率不快（缓）
- **头痛**：外周血管扩张状态下，颅内血管代偿性调节或炎症介质（缓激肽）作用于三叉神经血管系统
- **发热**：体温调定点轻度上移，但因汗出散热，呈现低热或中等发热

### 体质差异（桂枝汤 vs 麻黄汤）
- **麻黄汤证**：交感神经张力偏高，皮肤血管α受体敏感，汗腺胆碱能神经抑制性强 → 无汗、脉浮紧
- **桂枝汤证**：副交感张力偏高或自主神经调节阈值低，汗腺M3受体敏感，血管舒缩调节"迟钝" → 汗出、脉浮缓

### 免疫应答差异
- **麻黄汤证**：IL-1β、TNF-α、PGE₂大量释放，下丘脑体温中枢调定点大幅上移
- **桂枝汤证**：肥大细胞脱颗粒、组胺释放为主，H1受体激活 → 毛细血管扩张、通透性增加

### 方药生理学
- **桂枝**：桂皮醛扩张外周毛细血管，改善皮肤微循环
- **芍药**：芍药苷舒缓血管平滑肌，与桂枝形成"一散一收"
- **生姜**：促进胃液分泌与肠蠕动
- **大枣**：提供快速可吸收糖分
- **甘草**：甘草酸皮质激素样抗炎作用
