## 一、笔记原文摘要

太阳伤寒表实证，以无汗、恶寒、身疼痛、喘、头痛、脉浮紧、发热为特征，病机为寒邪束表、卫阳被郁、营阴凝滞。

### 核心链条（原文）
> **强烈寒冷刺激 → 皮肤冷觉/伤害性感受器强烈激活 → 下丘脑体温调节中枢启动"紧急保温模式" → 交感-肾上腺髓质系统（SAM轴）爆发性激活 → 外周血管强烈收缩（α受体） + 汗腺完全关闭（胆碱能抑制） → 体温调定点上移但散热通路阻断 → 产热剧增、热量蓄积 → 骨骼肌缺血缺氧 + 炎症介质堆积（身疼痛） + 气道阻力增加（喘） + 颅内血管代偿性扩张（头痛）**

### 分章节症状群机制
1. **无汗**：寒冷刺激 → TRPM8/TRPV1 → 下丘脑 → SAM轴 → 皮肤血管收缩 + 汗腺关闭
2. **恶寒**：外周血管收缩 → 皮肤血流量减少 → 皮肤温度下降 → 冷觉感受器持续报告"寒冷"
3. **身疼痛**：外周血管收缩 → 骨骼肌缺血缺氧 → 乳酸堆积 + 缓激肽/PGE2 → 痛觉敏化
4. **头痛**：体温调定点上移 + 散热阻断 → 核心体温升高 → 脑血流增加 + 炎症介质 → 三叉神经血管系统
5. **喘**：支气管黏膜充血水肿 + 平滑肌痉挛 → 气道阻力增加 + 肺泡J受体刺激 → 呼吸急促
6. **脉浮紧**：心输出量增加（浮） + 外周血管收缩（紧）
7. **发热**：致热原 → 体温调定点上移 + 散热阻断 → 高热
