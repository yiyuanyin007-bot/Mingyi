# 循证审计报告 · 文献验证工作流（v1.0）

> **文档性质**：工作标准（Standard Operating Procedure）  
> **适用范围**：本对话内所有「审计报告」的独立验证任务  
> **编制日期**：2026-06-21  
> **编制者**：审计智能体（经方学习系统协作者）  
> **关联文档**：`docs/循证文献检索工作手册.md`（检索端）、`docs/evidence/task_board.md`（任务看板）  
> **最后更新**：2026-06-21（v1.0 初始版）

---

## 1. 目的

防止循证文献检索环节产生以下三类不可接受的质量问题流入下游：

1. **引用幻觉（Citation Hallucination）**：AI 虚构看似合理的来源（作者、标题、DOI 均存在，但内容完全不符）。
2. **来源误标（Source Misclassification）**：将患者教育网站、商业博客、倡导组织误标为「同行评审」或「高 GRADE」证据。
3. **盗版/非法引用（Pirated Source）**：引用非授权上传的 PDF（如教材扫描件、期刊盗版），既无法律严谨性也无可验证性。

本工作流为审计智能体提供**可复现、可检查、可登记**的独立验证步骤。

---

## 2. 适用范围

| 适用 | 不适用 |
|------|--------|
| `docs/evidence/reports/*_evidence_audit.md` 中的参考文献清单 | 审计报告中的病理生理推论本身（那是循证文献检索专家的职责） |
| 每条引用的 URL 可达性、内容一致性、来源权威性 | 用户对笔记内容的医学正确性判断（需临床专家） |
| 任务看板状态流转（待验证 → 已通过/需修正） | 前端代码或卡片数据修改 |

---

## 3. 前置条件

每次执行本工作流前，必须确认：

- [ ] 已读取 `docs/evidence/task_board.md`，了解当前「待验证」任务列表
- [ ] 已读取目标审计报告（`docs/evidence/reports/{card_id}_evidence_audit.md`）
- [ ] 已确认本工作流由「审计智能体」角色执行，而非「循证文献检索专家」角色

## 4. 六阶段工作流

### 阶段 1：提取（Extraction）

**工具**：`PythonRun`

**目标**：从审计报告的 Markdown 表格中解析出所有参考文献，输出结构化 JSON。

**输入**：`docs/evidence/reports/{card_id}_evidence_audit.md` 的 `## 七、参考文献清单` 章节

**输出格式**：

```json
{
  "refs": [
    {
      "num": 1,
      "url": "https://pmc.ncbi.nlm.nih.gov/articles/PMC4858318/",
      "title": "Central Nervous System Control of Gastrointestinal Motility and Secretion",
      "author": "Browning & Travagli",
      "year": "2014",
      "source": "Frontiers in Neuroscience",
      "node": "XJZ-001"
    }
  ]
}
```

**关键检查点**：
- 表格是否完整解析（首尾行边界检测）
- 空字段（`-`）需保留原样，不可丢弃
- 输出 JSON 保存到临时目录，供后续阶段调用

---

### 阶段 2：分类（Classification）

**工具**：`PythonRun`（同阶段 1 脚本内完成）

**目标**：按域名/来源特征自动分级，标记高风险项。

**分类规则**（见第 5 章「来源分级规则」）：

| 类别 | 自动判定规则 | 风险等级 |
|------|-------------|----------|
| PMC/PubMed | `pmc.ncbi.nlm.nih.gov` | 低 |
| DOI/期刊 | `doi.org` 或 `10.` 开头 | 低 |
| 学术机构 | `frontiersin.org`, `springer.com`, `ncbi.nlm.nih.gov/books` | 低 |
| Preprint/论文库 | `semanticscholar.org`, `researchgate.net`, `arxiv.org` | 中 |
| 患者组织/科普 | `beyondceliac.org`, `webmd.com`, `healthline.com` | **高** |
| 商业公司/博客 | `.com` 个人域名、营销网站、`.directory` 等 | **高** |
| 可疑/未知 | 非标准域名、未来年份、Bing 缓存、网盘链接 | **高** |

**输出要求**：
- 在 JSON 中追加 `category` 和 `risk_level` 字段
- 对 `risk_level == 高` 的条目，必须进入阶段 3 的逐条验证
- 对 `risk_level == 低` 的 PMC/DOI 条目，可抽样验证（至少 2 条）

---

### 阶段 3：三维验证（3-Dimension Verification）

**工具**：`kimi_fetch_v2`（主力）+ `kimi_search_v2`（交叉验证）

**对每条高风险引用 + 抽样低/中风险引用，执行三个维度**：

#### 维度 A：URL 可达性

```
工具：kimi_fetch_v2
输入：引用 URL
输出：页面内容 / 错误信息
```

| 结果 | 处理 |
|------|------|
| 成功返回内容 | 进入维度 B |
| 403 Forbidden | 记录状态，尝试搜索引擎交叉验证 |
| 网络错误 / 超时 / DNS 失败 | 标记为「无法访问」，尝试搜索引擎交叉验证 |
| 返回内容但与标题严重不符 | 标记为「引用幻觉」，进入维度 C |

#### 维度 B：内容一致性

- 从 `kimi_fetch_v2` 返回的文本中提取页面标题
- 与报告中的 `title` 字段做字符串比对（允许简写差异，但不允许主题完全偏离）
- 核对作者名（全名 vs 简写可接受，但作者名完全错误不可接受）
- 核对年份（未来年份如 2025/2026 在当前时间点需特别标注，非绝对拒绝，但需确认是否已在线发表）

**判定标准**：

| 一致性 | 示例 | 结论 |
|--------|------|------|
| 完全匹配 | 报告标题 = 页面标题 | 通过 |
| 简写/缩写 | 报告 "Browning & Travagli" = 页面 "Kirsteen N Browning & R Alberto Travagli" | 通过 |
| 主题偏离 | 报告 "Glutamate/GABA imbalance" = 页面 "Sol Brah 极端饮食建议" | **引用幻觉，拒绝** |
| 无法核对 | 页面无标题、纯 PDF 无文本层 | 降级为「待人工复核」 |

#### 维度 C：来源权威性

基于域名 + 内容类型综合判定：

| 来源类型 | 权威性 | GRADE 上限 |
|----------|--------|-----------|
| PubMed / PMC / Nature / Lancet / JAMA 等 | 高 | 高 |
| 其他 SCI 期刊官网（Springer、Elsevier、Wiley） | 高 | 高 |
| NCBI Bookshelf / StatPearls / 权威教科书 | 中高 | 高 |
| 大学课程 PDF / 学位论文 | 中 | 中 |
| Semantic Scholar / ResearchGate（预印/全文） | 中 | 中 |
| 患者倡导组织 / 科普网站 | 低 | 极低 |
| 商业检测公司 / 健康博客 | 极低 | 极低 |
| 伪科学 / 阴谋论 / 极端健康社区 | 拒绝 | 拒绝 |
| 非授权盗版 PDF（网盘、.kg/.ru 等大学镜像） | 拒绝 | 拒绝 |

**关键原则**：
- 患者教育网站（如 BeyondCeliac）可以有价值，但**绝不**能评为「高 GRADE」或「直接验证」
- 博士论文可以提供证据，但**绝不**能评为「高 GRADE」（样本量、方法学局限）
- 任何 `.directory`、个人博客、Bing 缓存作为参考文献的，必须标记为「待替换」

---

### 阶段 4：生成验证附注（Annotation Generation）

**工具**：`PythonRun`

**目标**：为全部引用生成统一格式的验证附注表格，追加到审计报告末尾。

**输出格式**（Markdown 表格）：

```markdown
| 编号 | 来源分级 | URL可达 | 标题匹配 | 作者年份一致 | 来源权威性 | 验证状态 | 备注 |
|------|----------|---------|----------|-------------|------------|----------|------|
| 1 | PMC | 是 | 是 | 是 | 高 | 通过 | Browning & Travagli 2014, Compr Physiol |
| 21 | 边缘博客 | 是 | 否（严重不符） | 否 | 极低 | 需删除 | 实际内容为患者组织博客合集，与标题完全不符 |
```

**字段定义**：
- `来源分级`：阶段 2 的分类结果
- `URL可达`：是 / 否(403) / 否(网络错误) / 未验证
- `标题匹配`：是 / 推断是 / 否(严重不符) / 未验证
- `作者年份一致`：是 / 推断是 / 否 / 未验证
- `来源权威性`：高 / 中高 / 中 / 低 / 极低 / 拒绝
- `验证状态`：通过 / 待修正 / 需删除 / 未逐条验证
- `备注`：简短说明，包括具体发现的问题

---

### 阶段 5：回填验证结果（Backfill）

**目标**：在审计报告的 `## 验证结果` 章节写入复核结论。

**必须填写的字段**：

```markdown
## 六、验证结果

> **验证状态**：需修正 / 已通过
> **验证者**：审计智能体（经方学习系统协作者）
> **验证日期**：YYYY-MM-DD

### 验证意见

1. **Ref X (Title)** — 简短结论。具体证据。
2. **Ref Y (Title)** — 简短结论。具体证据。
...

### 修正建议

- [ ] Ref X：具体操作
- [ ] Ref Y：具体操作
...

### 验证总结

> 本报告 N 条引用中，验证发现 X 项需修正、Y 项需删除、Z 项通过。
> 建议：...
```

**回填位置**：替换审计报告中原有的 `## 六、验证结果` 占位内容（从 `> **验证状态**：未验证` 开始）。

**回填后追加**：阶段 4 生成的验证附注表格（作为 `## 八、参考文献验证附注` 或插入原章节后）。

### 阶段 6：更新任务看板（Task Board Update）

**目标文件**：`docs/evidence/task_board.md`

**状态流转**：

```
待验证 → 需修正（发现任何需修正项）
待验证 → 已通过（全部引用验证通过，无修正项）
```

**必须更新的字段**：

1. 顶部统计表：将任务数量从「待验证」移到「需修正」或「已通过」
2. 任务明细表：
   - 若「需修正」：在 `### 需修正` 表格中新增条目，填写 `验证完成时间`、`验证者`、`修正项数`、`修正摘要`
   - 若「已通过」：在 `### 已通过` 表格中新增条目
3. 更新日志：在 `## 更新日志` 中追加一行记录

## 5. 来源分级规则（白名单 / 黑名单）

### 5.1 白名单（高可信度，可信任）

| 域名模式 | 类型 | 备注 |
|----------|------|------|
| `*.ncbi.nlm.nih.gov` | 美国政府生物医学数据库 | PubMed、PMC、Bookshelf |
| `doi.org` | DOI 解析服务 | 永远优先使用 |
| `*.nature.com` | Nature 出版集团 | 包括子刊 |
| `*.springer.com` / `link.springer.com` | Springer | 包括 SpringerLink |
| `*.frontiersin.org` | Frontiers 期刊 | 开放获取 |
| `*.sciencedirect.com` | Elsevier | 需机构访问 |
| `*.wiley.com` | Wiley | 需机构访问 |
| `*.oxfordjournals.org` / `academic.oup.com` | OUP | 需机构访问 |
| `*.cambridge.org` | Cambridge | 需机构访问 |
| `*.bmj.com` | BMJ | 需机构访问 |
| `jamanetwork.com` | JAMA | 需机构访问 |
| `annals.org` | Annals of Internal Medicine | 需机构访问 |

### 5.2 灰名单（可用但需谨慎）

| 域名模式 | 类型 | 注意事项 |
|----------|------|----------|
| `semanticscholar.org` | AI 论文聚合 | 可能链接到非官方 PDF，需验证 |
| `researchgate.net` | 学术社交网络 | 预印本、作者自存档，非正式发表 |
| `arxiv.org` | 预印本服务器 | 未经同行评审 |
| `*.edu` / `*.ac.uk` / `*.ac.in` | 大学域名 | 课程材料、学位论文，非期刊 |
| `*.thesis` / `repository.*` | 机构库 | 学位论文，GRADE 上限「中」 |

### 5.3 黑名单（拒绝使用）

| 域名模式 | 类型 | 拒绝理由 |
|----------|------|----------|
| `*.directory` | 个人/边缘网站 | 无学术背书 |
| `bing.com/ck/a` | Bing 缓存 | 不稳定、不可追溯 |
| `*.wp-content/uploads/*.pdf`（非大学/期刊官网） | 非授权上传 | 疑似盗版 |
| `*.kg` / `*.uz` / 非学术国家域名上的医学教材 | 盗版镜像 | 非授权上传 |
| 患者组织博客（如 beyondceliac.org 的 /living/ 页面） | 倡导内容 | 非同行评审，但可保留作为补充参考，GRADE 极低 |
| 商业健康检测公司（如 nutripath.com.au） | 商业利益 | 营销内容 |
| 脊椎按摩协会 / 替代医学协会文件 | 非标准医学 | 无 PubMed 索引 |
| 伪科学社区（如极端饮食博客、阴谋论） | 伪科学 | 内容不可信 |

## 6. GRADE 复盘红线

审计智能体在验证时，必须核查原报告的 GRADE 评级是否违反了以下红线：

| 红线 | 说明 | 处理方式 |
|------|------|----------|
| 患者组织 / 科普网站 → 高 | BeyondCeliac、WebMD 等评为「高」 | 降级为「极低」 |
| 博士论文 → 高 | 学位论文评为「高」 | 降级为「中」 |
| 预印本 / 论文库 → 高 | arXiv、ResearchGate 评为「高」 | 降级为「中」 |
| 商业公司 PDF → 任何非极低 | 营销材料评为「低」以上 | 降级为「极低」 |
| 盗版 PDF → 任何等级 | 非授权教材扫描件 | 标记为「拒绝」，要求删除 |
| 引用幻觉 → 任何等级 | 标题与内容不符的来源 | 标记为「拒绝」，要求删除 |

## 9. 常见陷阱与识别信号

### 9.1 引用幻觉（Citation Hallucination）

**识别信号**：
- 来源标题听起来非常学术，但 URL 打开后是健康博客、个人论坛或完全无关的内容
- 作者名常见（如 "Faden et al."），但搜索不到该作者的该主题论文
- DOI 格式正确但 `doi.org` 无法解析
- 引用的期刊名与内容主题明显不相关

**处理**：标记为「需删除」，要求循证文献检索专家重新检索真实来源。

### 9.2 来源误标（Source Misclassification）

**识别信号**：
- 患者组织网站（如 `beyondceliac.org`）被标记为「高 GRADE」
- 博客文章被标记为「系统综述」
- 商业公司白皮书被当作「临床试验」

**处理**：降级 GRADE，明确要求标注来源真实类型。

### 9.3 盗版 PDF（Pirated Source）

**识别信号**：
- 经典医学教材（如 Harrison's、Robbins）出现在非官方域名（如 `.kg`、`.uz`、网盘）
- URL 包含 `wp-content/uploads/` 且域名不是出版商或大学
- PDF 无 DOI、无版权页、无页码

**处理**：标记为「拒绝」，要求替换为合法来源（PubMed 综述、机构订阅、或教科书引用格式而非直接链接）。

### 9.4 未来年份（Future Year）

**识别信号**：
- 当前日期为 2026-06-21，但引用标注为 2025 或 2026
- 论文 DOI 存在但尚未在 PubMed 索引

**处理**：标注「early online / 预印本」，不直接拒绝，但要求确认是否已正式发表。

## 10. 试点案例：小建中汤（xiao-jian-zhong-tang）

**任务 ID**：XJZ-20260620-001  
**审计日期**：2026-06-20  
**验证日期**：2026-06-21  
**引用总数**：29 条

### 10.1 验证样本选择策略

| 风险等级 | 抽样数量 | 代表条目 |
|----------|----------|----------|
| 低（PMC/DOI） | 3 | Ref 1 (PMC), Ref 4 (Nature DOI), Ref 10 (PMC) |
| 中（Preprint/机构） | 2 | Ref 17 (博士论文), Ref 12 (ResearchGate) |
| 高（博客/患者组织） | 3 | Ref 6 (BeyondCeliac), Ref 21 (Parascientific), Ref 29 (Bing缓存) |
| 可疑（盗版/未知） | 2 | Ref 9 (jaiu.kg), Ref 2 (ScienceOpen 403) |

### 10.2 关键发现

| 问题 | 引用 | 详情 | 结论 |
|------|------|------|------|
| 引用幻觉 | Ref 21 | 标题声称 "Glutamate/GABA imbalance"，实际是极端饮食博客合集 | 需删除 |
| 盗版来源 | Ref 9 | Harrison's Manual 出现在吉尔吉斯斯坦大学域名，无法访问 | 需删除 |
| 来源误标 | Ref 6 | BeyondCeliac 患者组织网站被标为「高 GRADE」 | 降级为「极低」 |
| 链接失效 | Ref 2 | ScienceOpen 返回 403，但论文本身真实（AMM 2026） | 待修正链接 |
| 来源不稳定 | Ref 29 | Bing 缓存链接，无学术背书 | 建议删除 |

### 10.3 验证后统计

```
29条引用中：
- 通过（直接验证）：3 条（Ref 1, 4, 10）
- 未逐条验证但推断可信（PMC/期刊）：6 条
- 需修正：2 条（Ref 2 链接，Ref 6 GRADE）
```
