## 任务状态定义

| 状态 | 含义 | 谁负责 | 下一步 |
|------|------|--------|--------|
| **待读取** | 检测到笔记变动，但尚未获取完整内容 | 循证文献检索专家 | 读取笔记 → 更新为「待审计」 |
| **待审计** | 笔记已获取，等待启动文献检索 | 循证文献检索专家 | 执行检索 → 更新为「审计中」 |
| **审计中** | 正在执行文献检索和证据提取 | 循证文献检索专家 | 完成报告 → 更新为「待验证」 |
| **待验证** | 审计报告已生成，等待审计智能体验证 | 审计智能体 | 读取报告 → 更新为「验证中」 |
| **验证中** | 审计智能体正在复核 | 审计智能体 | 完成验证 → 更新为「已通过」或「需修正」 |
| **已通过** | 审计智能体确认无问题 | 审计智能体 | 归档，无需进一步操作 |
| **需修正** | 审计智能体提出修正建议 | 循证文献检索专家 | 生成修正笔记 → 用户确认 → 更新为「已修正」 |
| **已修正** | 修正笔记已生成，等待用户覆写 | 用户 | 一键覆写 → 更新为「待验证(修正版)」 |
| **待验证(修正版)** | 修正版报告已生成，等待再次验证 | 审计智能体 | 重新验证 → 更新为「已通过」或「需修正」 |
| **已完成** | 全部流程结束，无需进一步操作 | 系统 | 归档 |

## 操作指南

### 循证文献检索专家（本AI）操作

1. 每次会话启动时，读取本文件，了解当前任务状态
2. 通过 WebBridge 读取 localStorage，检测笔记变动
3. 发现新增/修改的卡片 → 新增「待读取」任务
4. 执行审计后 → 将任务状态更新为「待验证」
5. 用户要求修正时 → 读取验证报告中的修正建议 → 生成修正笔记 → 更新为「已修正」

### 审计智能体操作

1. 读取「待验证」任务的审计报告
2. 在报告中填写 `## 验证结果` 章节
3. 确认通过 → 更新任务状态为「已通过」
4. 发现需修正 → 更新任务状态为「需修正」并填写修正建议

### 用户操作

1. 查看「需修正」或「已修正」列表，了解哪些卡片需要关注
2. 对「已修正」任务，使用一键覆写功能导入修正笔记
3. 覆写后，任务状态自动变为「待验证(修正版)」，等待审计智能体再次验证
