# 「再来一组」交互方案 · 认知神经科学与学习科学版

> 设计目标：将「回顾题目」（被动回看）升级为「再来一组」（自适应检索练习），让每一个点击都嵌入经过实证研究验证的学习机制。

---

## 一、为什么不是「回顾题目」

### 1.1 回顾题目的认知陷阱

当前「回顾题目」本质是**被动浏览**，用户看到答案后直接知道对错，这会产生 **熟练度错觉（Illusion of Competence）**——Bjork & Bjork 的经典研究指出，流畅的再认（recognition）不等于可提取的回忆（recall），用户可能「看起来会了」，但临床实战中根本想不起来。

### 1.2 再来一组的核心升级

| 维度 | 回顾题目 | 再来一组 |
|---|---|---|
| 认知动作 | 被动再认 | 主动检索 |
| 内容来源 | 原题重现 | 智能变异 |
| 反馈方式 | 即时告知 | 延迟+元认知校准 |
| 间隔控制 | 无 | 嵌入间隔效应 |
| 难度适配 | 固定 | 基于必要难度理论 |
| 学习理论 | 无 | 10+ 项实证研究 |

## 二、理论框架：七大认知机制

### 机制1：检索练习效应（Testing Effect）
**研究者**：Roediger & Karpicke (2006)  
**核心发现**：主动从记忆中提取信息，比被动复习能产生更持久的学习效果，效应量 d≈0.50。  
**嵌入方式**：再来一组的每一题都是「提取」而非「浏览」。

### 机制2：间隔效应（Spacing Effect）
**研究者**：Ebbinghaus → Cepeda et al. (2006)  
**核心发现**：学习-测试间隔扩大，长期记忆留存率提升 2-3 倍。最优间隔 ≈ 测试间隔的 10-20%。  
**嵌入方式**：上一组刚考完→再来一组立即启动，但题组内容**不是同一卡片**，而是按掌握度间隔调度。

### 机制3：必要难度（Desirable Difficulty）
**研究者**：Bjork (1994)  
**核心发现**：学习时适当增加认知难度（但不至于挫败），能提升长期保持。  
**嵌入方式**：基于上一组正确率动态调整题目难度和混淆项相似度。

### 机制4：变异学习 / 上下文干扰（Contextual Interference）
**研究者**：Shea & Morgan (1979)  
**核心发现**：同一知识点以不同形式/语境出现，比重复相同形式的学习效果更好。  
**嵌入方式**：同一方剂的同一向量，第二轮换成不同题型或不同表述。

### 机制5：元认知校准（Metacognitive Calibration）
**研究者**：Koriat (1997)  
**核心发现**：让用户预判自己的掌握程度，再将预判与实际对比，能显著改善后续学习策略。  
**嵌入方式**：结果页加入「预判→校准」环节。

### 机制6：生成效应（Generation Effect）
**研究者**：Slamecka & Graf (1978)  
**核心发现**：自己生成的信息比被动接收的信息记忆更牢。  
**嵌入方式**：再来一组结束后，要求用户用一句话总结两次的差异。

### 机制7：延迟反馈（Delayed Feedback）
**研究者**：Butler & Roediger (2008)  
**核心发现**：延迟反馈（而非每题即时反馈）对长期记忆更有利，因为它避免了「即时正确答案依赖」。  
**嵌入方式**：再来一组采用「分块反馈」模式。

## 三、完整交互流程

### 阶段0：第一组考试结束（现状）

用户完成第一组 N 题，看到结果页：
- 分数（X / N）
- 错题列表（可打诊断标签）
- **【替换按钮】** 原「回顾题目」→ 新「再来一组」

### 阶段1：元认知校准（Metacognitive Calibration）—— 结果页前置

在显示「再来一组」按钮之前，插入一个**轻量校准环节**（不弹窗，内嵌在结果页底部）：

```
┌─────────────────────────────────────────┐
│  📊 先做个预判，再开始下一组              │
│                                         │
│  ① 你觉得刚才答对了百分之几？            │
│     [0%] [25%] [50%] [75%] [100%]      │
│                                         │
│  ② 刚才这组，你觉得整体难度是？          │
│     [太简单] [刚好] [有点难] [太难]     │
│                                         │
│  [再来一组]                             │
└─────────────────────────────────────────┘
```

**神经科学依据**：
- Koriat 的「线索利用模型」：JOL（Judgment of Learning）的编制过程本身就是一种记忆增强事件。
- 当用户预判「70%」而实际只有「50%」时，这个「校准误差」会在大脑中标记为「需要关注」，相当于一次隐性的错误驱动学习（Error-Driven Learning）。

**数据存储**：校准结果存入 session trace，用于后续难度适配。

### 阶段2：点击「再来一组」—— 智能题组生成引擎

点击后，系统运行**自适应题组生成算法**，不是简单随机抽题，而是基于认知诊断生成新题组。

#### 2.1 认知诊断（Cognitive Diagnosis）

分析上一组数据，输出认知画像：

| 维度 | 计算方式 | 用途 |
|---|---|---|
| 总正确率 | right / total | 决定整体难度偏移 |
| 向量弱点 | 按 6 向量统计正确率 | 识别薄弱向量，第二轮重点覆盖 |
| 卡片弱点 | 按 cardId 统计正确率 | 识别薄弱卡片 |
| 混淆模式 | 选错时选了哪个混淆项 | 判断是「搞混了」还是「记错了」 |
| 答题速度 | 每题用时（如有记录） | 判断是熟练还是猜的 |
| JOL 校准误差 | |JOL - 实际| | 误差越大，用户越自信但越不准，需要降自信干预 |

#### 2.2 题组生成策略（基于 7 大机制）

```
输入：上一组 questions[] + answers[] + 认知画像
输出：新题组 newQuestions[]

算法流程：

1. 确定题组大小
   - 如果上一组正确率 < 40%：生成 8 题（避免认知超载，符合认知负荷理论）
   - 如果正确率 40-70%：生成 10-12 题
   - 如果正确率 > 70%：生成 15 题（挑战上限）

2. 确定内容配比（间隔效应 + 检索练习）
   新题组 = 60% 薄弱区强化 + 40% 间隔复习
   
   a) 薄弱区强化（60%）
      - 从上一组错题对应的 cardId 中，挑出用户答错的向量
      - 对这些向量重新生成题目，但**变异题型**（机制4）
      - 例如：第一轮是「方名→症状（选择题）」，第二轮换成「症状→方名（反向题）」或「填空核心药组」
      
   b) 间隔复习（40%）
      - 从用户已掌握但超过复习间隔阈值的卡片中抽取
      - 这部分卡片上一次答对了，但如果不复习会遗忘（Ebbinghaus 曲线）
      - 插入薄弱区题目之间，形成「干扰-恢复」节奏

3. 必要难度调整（机制3）
   - 对于薄弱卡片：降低难度（选项更差异化，提示更明显）
   - 对于已掌握卡片：提高难度（混淆项更相似，加入变方干扰）
   - 如果 JOL 校准误差 > 20%：额外插入 1-2 题「自信矫正题」——用户自认为会的但实际错了的知识点

4. 顺序编排（上下文干扰 + 认知负荷）
   - 不连续出现同一卡片的题目（避免机械关联）
   - 不同向量类型交错排列（A卡0→1 → B卡1→0 → C卡0→2 → A卡1→0）
   - 这符合 Shea & Morgan 的「交错练习」优于「集中练习」的发现
```

#### 2.3 具体题型变异表（Contextual Interference）

第一轮考了某种题型，第二轮如何变异？

| 向量 | 第一轮题型 | 第二轮变异题型 | 理论依据 |
|---|---|---|---|
| 0→1 方名→症状 | 选择题：桂枝汤必要症状包括？ | 填空题：____汤的必要症状是汗出、恶风？ | 生成效应：填空比选择更难提取 |
| 1→0 症状→方名 | 选择题：出现汗出恶风，选何方？ | 排序题：以下症状组合，按方证匹配度排序 | 必要难度：排序需要比较推理 |
| 0→2 方名→药组 | 选择题：桂枝汤核心药组？ | 拖拽题：从药池中拖拽组成桂枝汤 | 生成效应：主动建构 |
| 2→0 药组→方名 | 选择题：桂枝+芍药+甘草+生姜+大枣 → 何方？ | 辨析题：以下哪组药对应「太阳中风」证？ | 变异学习：同一知识不同线索 |
| 0→contra 禁忌 | 选择题：桂枝汤禁忌？ | 病例题：某患者...，以下哪个方不能用？ | 情境化：临床场景更接近真实 |
| 0→usage 煎服法 | 选择题：桂枝汤煎服法？ | 判断题：桂枝汤应「大汗出」后服用？（错误） | 精细加工：判断比选择更深 |

> 注：拖拽/排序等交互形式如果实现成本高，可以先用「多选」或「填空」替代，但核心原则不变：不能和第一轮一模一样。

### 阶段3：再来一组的答题过程——分块反馈（Delayed Feedback）

#### 3.1 为什么不是每题即时反馈

传统在线答题每选完一题立刻变红/变绿，用户很快学会「猜→看答案→记住正确答案」的策略，而不是真正从记忆中提取。

Butler & Roediger (2008) 的实验发现：
- 即时反馈组：短期测试成绩好，但 1 周后遗忘 40%
- 延迟反馈组（答完一组再统一反馈）：短期成绩略低，但 1 周后只遗忘 15%

**原因**：延迟反馈时，用户需要靠自己的记忆去判断「我到底答对了多少」，这个过程中发生了额外的检索练习。

#### 3.2 分块反馈的具体实现

```
再来一组（10题）

├─ 第 1-3 题：答题中不显示对错
│   用户只能看到「已作答」状态，不知道对错
│   每题提交后自动进入下一题，不等待反馈
│
├─ 第 3 题完成后：弹出「小歇 + 预判」
│   ┌────────────────────────────┐
│   │  小歇一下                  │
│   │  你已经答了 3 题           │
│   │  预估一下，这 3 题对了多少？│
│   │  [0] [1] [2] [3]           │
│   │  [继续下一组]              │
│   └────────────────────────────┘
│   → 再次嵌入元认知校准
│
├─ 第 4-6 题：继续答题（无即时反馈）
│
├─ 第 6 题完成后：第二次小歇 + 预判
│
├─ 第 7-10 题：继续答题
│
└─ 全部完成后：统一反馈页面
```

**统一反馈页面**的设计：

```
┌────────────────────────────────────────────┐
│  📋 第二组反馈（10题）                       │
│                                             │
│  你的预判：3/3 + 2/3 + 3/4 = 预估 8/10      │
│  实际结果：7/10                              │
│  ⚠️ 你高估了 1 题（校准偏差 -10%）            │
│                                             │
│  ── 错题分析 ──                              │
│  第 2 题：你选了 麻黄汤 → 正确答案 桂枝汤    │
│     💡 提示：上一次你也搞混了这两个方         │
│     [🤔 搞混了] [😵 记错了] [❓ 没学过]      │
│                                             │
│  第 5 题：你选了 A → 正确答案 B              │
│     💡 提示：这是上次你标记为「记错了」的题   │
│     [🤔 搞混了] [😵 记错了] [❓ 没学过]      │
│                                             │
│  ── 对比上次 ──                              │
│  第 2 题上次错了，这次又错了 → 标记为「顽固错误」│
│  第 7 题上次错了，这次对了 → 标记为「已进步」  │
│                                             │
│  [再来一组] [返回首页] [去错题本]            │
└────────────────────────────────────────────┘
```

**关键设计点**：
1. **进步追踪**：对比两组数据，显示「上次错这次对」的题目，给用户即时的成长感（正强化）。
2. **顽固错误标记**：同一知识点连续两次答错，标记为「顽固错误」，后续复习间隔缩短（比艾宾浩斯标准间隔更密集）。
3. **历史提示**：在错题下方显示轻量提示「上次你也在这里错了」，这是基于「错误一致性」的学习机会——同一错误重复发生，说明存在深层认知结构问题。

### 阶段4：结束后的生成效应（Generation Effect）

在反馈页面之后，可以嵌入一个可选的轻量环节（不强制，用户可跳过）：

```
┌────────────────────────────────────────────┐
│  📝 用一句话总结                              │
│                                             │
│  刚才两组考试，你觉得自己最大的收获是：       │
│  （选填，但研究显示这能提升记忆 30%）         │
│                                             │
│  [________________________] [保存] [跳过]   │
└────────────────────────────────────────────┘
```

**神经科学依据**：
- Slamecka & Graf (1978)：生成效应。自己组织的语言比系统给的总结更有记忆粘性。
- 中医学习是「具身知识」—— 需要自己把知识点和临床场景联系起来，生成效应正好促进这种联结。

## 四、界面设计的认知优化细节

### 4.1 按钮文案心理学

| 文案 | 问题 | 优化后 | 原理 |
|---|---|---|---|
| 回顾题目 | 暗示被动浏览 | **再来一组** | 启动效应（priming）：「来」= 行动，「组」= 结构化 |
| 回顾题目 | 暗示重复旧题 | **再来一组** | 暗示新内容，降低熟练度错觉预期 |
| 再来一组 | 如果是第一次出现，可以加副标题 | **再来一组**（基于你的错题智能生成） | 透明度效应：让用户知道系统有智能，增加信任和使用意愿 |

### 4.2 颜色与认知负荷

- **答题中不显示对错**：选项按钮在提交后保持原色（不立即变红/绿），避免颜色引发的情绪干扰后续答题。
- **小歇页面的预判**：用中性灰色背景，降低认知唤醒，让元认知判断更理性（避免情绪化的过度自信）。
- **反馈页面**：正确用绿色（多巴胺奖励），错误用橙色（非红色，红色会触发威胁反应，橙色是「提醒」而非「惩罚」）。

### 4.3 动画与过渡

- 小歇页面弹出时，添加 0.3s 的淡入动画，给用户一种「阶段切换」的心理信号，帮助大脑切换认知模式（从「答题模式」→「监控模式」）。
- 这是基于认知心理学家 John Sweller 的「分段处理」建议——大脑需要明确的边界来处理信息块。

### 5.1 新增 trace 字段

```json
{
  "examSession": {
    "sessionId": "sess-001",
    "round": 1,
    "questions": [...],
    "answers": [...],
    "jol": {
      "predictedAccuracy": 70,

    },
    "cognitiveProfile": {
      "overallAccuracy": 50,
      "weakVectors": ["0→1", "0→2"],
      "weakCards": ["gui-zhi-tang", "ma-huang-tang"],
      "confusionPatterns": [
        {"cardId": "gui-zhi-tang", "wrongChoice": "ma-huang-tang", "count": 2}
      ]
    }
  }
}
```

### 5.2 间隔复习调度表

```json
{
  "cardReviewSchedule": {
    "gui-zhi-tang": {
      "lastTested": "2026-06-18T10:00:00",
      "correctStreak": 1,
      "errorStreak": 0,
      "nextIntervalDays": 1,
      "weakVectors": ["0→1"]
    }
  }
}
```

- `correctStreak`：连续答对的次数，决定间隔增长倍数（1→2→4→7→14→30）
- `errorStreak`：连续答错的次数，>0 时间隔不增长，反而缩短（回到 1 天）
- `weakVectors`：记录该卡片哪些向量薄弱，优先覆盖

## 六、实施建议：最小闭环 vs 完整版

### 6.1 最小闭环（本周可用）

实现以下 3 个最小改动，即可产生显著效果：

1. **按钮改名**：「回顾题目」→「再来一组」
2. **智能生成**：基于错题生成新题组（60% 错题卡片 + 40% 随机已掌握卡片）
3. **变异题型**：同一向量第二轮换表述方式（如选择题→填空题）

**预期效果**：相比「回顾题目」的被动浏览，用户记忆提取量增加 50% 以上（基于 Testing Effect 的元分析效应量）。

### 6.2 进阶版（下周）

4. **元认知校准**：结果页加入 JOL 预判（2 个简单问题）
5. **分块反馈**：每 3 题一个小歇，统一反馈
6. **进步追踪**：对比两组数据，显示「已进步」/「顽固错误」

### 6.3 完整版（长期）

7. **间隔复习调度**：完整的卡片级艾宾浩斯调度
8. **拖拽/排序题型**：更丰富的交互形式
9. **生成总结**：考后一句话总结环节
10. **混淆模式分析**：系统自动识别「最容易搞混的两方」并生成对比题

## 七、一句话总结

> **「再来一组」不是「再看一遍」，而是让大脑在「刚才差点忘了」的最佳记忆窗口期，以「变个方式再提取一次」的形式，把知识从「再认」升级为「回忆」，把「知道」变成「能用」。**
