## 五、处方解析经验（不可重复踩坑）

### 5.1 从「位置正则」到「已知药名精确匹配」

- **早期错误**：用正则 `([^，。、\s]{1,6}[\d]+[克g])` 按位置匹配，导致「夏 10 克」截断、数字无药名等错误。
- **正确做法**：
  1. 建立 291 个已知药名库（从卡片 herbs + 常见别名）。
  2. 按药名精确匹配：搜索每个已知药名，再找后面的数字 + 单位。
  3. 按长度降序匹配：先匹配「炙甘草」再匹配「甘草」，防止截断。
  4. 边界检查：药名前后不能是中文汉字。
- **结果**：34 个医案全部解析成功，每案 10-17 味药。

### 5.2 处方结构化输出格式

```json
{
  "prescription_structured": [
    {"name": "柴胡", "dose": "10克"},
    {"name": "黄芩", "dose": "10克"}
  ]
}
```

- 药名必须映射到标准名（通过 `herb_alias_map.json`）。
- 剂量保留原始文本，前端负责换算显示。

### 6.2 前端兼容层

`app/herb-aliases.js`：

- 维护：当 `herb_alias_map.json` 更新时，需同步更新 `herb-aliases.js`。

## 九、工作红线与协作接口

### 9.1 与「条文系统对话」的红线

> **核心原则**：方剂系统只管卡片数量和结构；条文系统只管条文内容。

| 做 | 不做 |
|---|---|
| 创建新卡片 JSON（id, name, data.canonical） | 不写条文讲解、不写刘渡舟/胡希恕观点 |
| 检查本地资料是否齐全，标记缺口 | 不从资料中提取条文内容 |
| 通知条文系统「卡片已创建，请补充内容」 | 不直接修改 `source_cards.json` |
| 登记 CHANGELOG（SH 编号） | 不登记条文系统的变更 |

**协作流程**：
1. 数据层创建新卡片 → 登记 CHANGELOG → 生成提示词。
2. 用户转发提示词给条文系统对话。
3. 条文系统补充 `source_annotations` → 登记自己的 CHANGELOG。
4. 卡片完整，通知操作系统对话更新 UI。

**提示词模板**：`docs/给条文系统的提示词模板.md`（以及 `docs/给条文系统的提示词-Batch5.md` 等）。

### 9.2 与「操作系统对话」的红线

> **核心原则**：数据内容 vs 前端交互，灰色地带显式协商。

| 数据层负责 | 交互层负责 |
|---|---|
| `data/*.json` 的结构与内容 | `app/index.html` 的渲染与交互 |
| 药名映射表内容 | 映射表的加载策略（`<script src>`） |
| JSON 合法性验证 | 浏览器语法验证、UI 测试 |
| Schema 变更通知 | 新字段的渲染代码 |

**已协商共识**：
- `window.HERB_ALIAS_MAP` 页面加载后必须可用。
- 弹窗内跳转用 `handleModalGoToLearn(id)`，不要直接 `goToLearn();closeModal()`。
- 任何 Schema 变更前，先更新接口契约文档，另一方确认后再实施。

### 9.3 问题归属速查

| 用户反馈 | 归属方 |
|---|---|
| "卡片不显示" / "卡片数量不对" | 数据层 |
| "剂量显示不对" / "药名找不到" | 数据层（先查数据）→ 交互层（数据对但渲染错） |
| "点击没反应" / "弹窗空白" | 交互层 |
| "内容重复/不相关" | 数据层 |

## 十二、已踩的坑（不再重复）

| 坑 | 根因 | 解决 |
|---|---|---|
| 处方解析出「夏 10 克」 | 正则按位置匹配，不识别药名边界 | 已知药名精确匹配 + 长度降序 |
| file:// 下 fetch 失败 | 没确认用户打开方式 | `<script src>` 加载 JS 文件 |
| 弹窗内跳转无反应 | `goToLearn();closeModal()` 冲突 | `handleModalGoToLearn()` 封装 |
| 控制台建议用户不会 | 假设用户是开发者 | 顶部栏加按钮，零门槛交互 |
| 别名映射不生效 | 外部 JSON 加载失败 | 硬编码 fallback + JS 文件加载 |
| 大段文字难读 | 没做内容结构化 | bullet points + 卡片式排版 |
| 弹窗内显示 slug | `q.correct` 直接暴露给用户 | `formatCorrectAnswer()` 格式化 |
| 卡片注入成二维数组 | `const CARDS = [` + `json.dumps([...])` 双重括号 | `const CARDS = ` + `json.dumps(...)` |
| 批量修改未登记 CHANGELOG | 多会话并行，假设别人会登记 | 每个会话独立登记，不依赖他人 |
| 临时文件未清理 | 会话结束未清理 | `governance.py clean-temp` |
| PowerShell 中文回显不可信 | 代码页不一致 | 以文件内容为准，不信任终端 |
| mastery 键名格式错误 | Batch 5+ 生成脚本未统一箭头 | 接班后首要修复 |
