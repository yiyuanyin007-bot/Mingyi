## 一、设计原则

### 1.1 第一性原理

> **设计服务于"认知训练"，不是"装饰"。**

- 减少认知负荷：界面简洁、信息层级清晰
- 强化训练反馈：答题结果、掌握度、进度一目了然
- 尊重中医传统：用传统色（赭石/黛青/朱砂）营造文化氛围，但不喧宾夺主
- 暗色模式护眼：长时间学习场景需要低对比度暗色主题

### 1.2 设计关键词

| 关键词 | 含义 | 设计表达 |
|--------|------|----------|
| **纸质** | 像读一本古医书 | 米白背景、纸张纹理（预留）、宋体标题 |
| **克制** | 不堆砌功能 | 留白充足、阴影克制、圆角统一 |
| **精确** | 训练需要精确反馈 | 颜色语义明确（红=错、绿=对、赭石=品牌） |
| **流动** | 学习是渐进的过程 | 过渡动画平滑、进度可视化 |

## 八、暗色模式规范

### 8.1 映射规则

| 浅色模式 | 暗色模式 | 说明 |
|----------|----------|------|
| brand-primary (赭石) | brand-primary (金色) | 品牌色替换为金色，保持识别度 |
| bg-body (米白) | bg-body (墨色) | 背景反转 |
| text-primary (炭灰) | text-primary (米白) | 文字反转 |
| shadow-sm | shadow-sm | 阴影不变，但透明度降低 |
| border (浅灰) | border (深灰) | 边框变亮（在暗色中"亮"=相对亮） |

### 8.2 暗色模式特殊处理

- 图片亮度降低：使用 `filter: brightness(0.85)`
- 阴影减弱：降低透明度
- 避免纯黑：背景用 #1E1E1E 而非 #000000
- 焦点环：金色 `shadow-focus: 0 0 0 3px rgba(201, 162, 39, 0.3)`
