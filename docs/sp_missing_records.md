- [ ] **大承气汤**（da-cheng-qi-tang-src-001）：

  - 标准条文（第208条）："阳明病，脉迟，虽汗出不恶寒者，其身必重，短气，腹满而喘，有潮热者，此外欲解，可攻里也。手足濈然汗出者，此大便已硬也，大承气汤主之。"
  - **冲突**：source_cards.json 中症状池有"绕脐痛""手足濈然汗出"，但原文中未提及。需确认是否以 symptom_pool 为准，或补充完整条文。

- [ ] **白虎汤**（bai-hu-tang-src-001）：
  - `source_cards.json` 原文："伤寒脉滑而厥者，里有热，白虎汤主之。"
  - 标准条文（第176条/第350条）：存在版本差异，宋本第176条为"伤寒，脉浮滑，此以表有热，里有寒，白虎汤主之"；成本有差异。
  - **冲突**："表有热里有寒"的表述与阳明经证"大热大汗大渴脉洪大"的经典白虎汤证有出入。需确认使用哪个版本。

- [ ] **调胃承气汤**（tiao-wei-cheng-qi-tang-src-001）：
  - `source_cards.json` 原文："发汗后恶寒者，虚故也。不恶寒，但热者，实也，当和胃气，与调胃承气汤。"
  - 标准条文（第70条）："发汗后恶寒者，虚故也。不恶寒，但热者，实也，当和胃气，与调胃承气汤。"
  - **冲突**：`source_cards.json` 中标注为"阳明病篇"，但第70条在部分版本中归属太阳病篇。需确认篇章归属。

  - **冲突**："咳痰黄"为后世临床补充，非原文。需确认是否保留在临床映射中，但标注来源。
