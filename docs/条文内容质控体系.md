## 1. 质量分级标准

| 级别 | 定义 | 判定条件 | 修复优先级 |
|---|---|---|---|
| **P0 · 致命** | 数据缺失或格式错误，面板无法展示 | text 为空或 < 10 字；annotations 为 null；JSON 结构损坏 | 立即 |
| **P1 · 严重** | 内容混排，标签未分离 | text 中混有注家讲解（如"刘渡舟""胡希恕"出现在 text 中）；annotations 键值对错位 | 24h 内 |
| **P2 · 中等** | 内容可展示但可能截断或缺失注家 | text 长度 > 500 但无注家标签；旧格式 summary 截断；OCR 错误 | 本周内 |
| **P3 · 轻微** | 格式良好，可优化 | 标签命名不规范；内容可补充扩展；meta 信息缺失 | 下次迭代 |
| **OK** | 符合标准 | 结构完整，标签分离，内容完整 | 无需修复 |

## 2. 数据 Schema 规范

### 2.1 新格式（推荐）

```json
{
  "source_annotations": {
    "references": [
      {
        "source_id": "shl-XXX",
        "source_name": "伤寒论",
        "article_number": "第XXX条",
        "text": "条文原文（纯条文，无注家内容）",
        "annotations": {
          "刘渡舟": "刘渡舟讲解完整内容",
          "胡希恕": "胡希恕讲解完整内容",
          "个人总结": "个人总结内容",
          "方义": "方义解析（可选）"
        }
      }
    ],
    "meta": {
      "batch_id": "SH-YYYYMMDD-NNN",
      "completed_at": "2026-06-18T12:00:00+08:00",
      "source_type": "xiaohongshu_teacher_notes",
      "coverage_note": "说明来源覆盖情况"
    }
  }
}
```

### 2.2 关键约束

| 字段 | 约束 | 错误示例 |
|---|---|---|
| `text` | 必须非空；长度 ≥ 20 字；不得包含"刘渡舟""胡希恕""个人总结" | 空字符串；包含注家名 |
| `annotations` | 必须为 object，不能为 null；键名规范 | null；键名为"刘渡舟讲解" |
| `annotations.*` | 值非空时长度 ≥ 30 字 | 空字符串；"暂无" |
| `article_number` | 必须包含"第"和"条" | "317"；"伤寒论第317" |
| `meta.batch_id` | 格式 `SH-YYYYMMDD-NNN` | 缺失；格式错误 |

## 3. 检查流程（自动化）

### 3.1 每日自动检查（脚本化）

```python
def qc_check(card):
    issues = []
    
    # P0 检查
    for ref in card.get('source_annotations', {}).get('references', []):
        if not ref.get('text', '').strip():
            issues.append('P0: text 为空')
        if ref.get('annotations') is None:
            issues.append('P0: annotations 为 null')
        if len(ref.get('text', '')) < 20:
            issues.append('P0: text 过短')
    
    # P1 检查
    for ref in card.get('source_annotations', {}).get('references', []):
        text = ref.get('text', '')
        for name in ['刘渡舟', '胡希恕', '个人总结', '方义']:
            if name in text:
                issues.append(f'P1: text 中混有"{name}"')
    
    # P2 检查
    for ref in card.get('source_annotations', {}).get('references', []):
        text = ref.get('text', '')
        annotations = ref.get('annotations', {})
        if len(text) > 500 and not any(k in annotations for k in ['刘渡舟', '胡希恕']):
            issues.append('P2: text 超长但无注家标签')
    
    return issues
```

### 3.2 人工抽查（每周）

- 随机抽取 10% 卡片
- 在浏览器中打开 slidePanel，验证：
  1. 标签切换是否正常
  2. 内容是否完整无截断
  3. 键盘快捷键是否生效
- 记录问题到 `docs/qc_issues.md`

1. **小红书针道轩笔记**（已提取，优先使用）
