## 一、高优先级 Bug（功能性阻断，需立即修复）

### Bug-1：今日复习键盘交互中途失效

| 项 | 描述 |
|---|---|
| 现象 | 点击「今日复习」→ 第一题作答后 → 第二题起键盘全部失效 |
| 失效按键 | 数字键 1/2/3/4、上一题 `[`、下一题 `]`、Enter、空格 |
| 期望 | 整个考试流程键盘交互全程可用 |
| 排查方向 | `handleKeydown` 事件监听可能在视图切换时被移除；或 `state.exam.answers[state.exam.current]` 状态判断逻辑在第二题时异常 |

### Bug-2：聚类复习按钮无响应

| 项 | 描述 |
|---|---|
| 现象 | 搜索结果或标签聚类后，点击「📋 聚类复习」按钮 → 无任何反应 |
| 期望 | 正常生成并进入考试 |
| 排查方向 | `startSearchClusterExam` / `startTagClusterExam` → `startClusterExam` 链路的 `initExam` 或 `setPage` 调用异常；或 `searchState.filteredCards` / `activeTag` 为空导致早期 return |

### Bug-3：学习页复习题点击无反应

| 项 | 描述 |
|---|---|
| 现象 | 在学习页面中点击复习题（如 0→1 / 1→0 等向量题）→ 毫无响应 |
| 期望 | 点击后进入对应向量的练习 |
| 排查方向 | 学习页中的向量题按钮未正确绑定 `startPractice` 或 `onPractice` 回调；或 `renderLearnView` 未接收/处理 `onPractice` 参数 |

### Bug-4：错题复习无法进入

| 项 | 描述 |
|---|---|
| 现象 | 今日完成 2 对 2 错 → 点击错题复习 → 无法进行复习 |
| 期望 | 从错题列表选择或直接进入错题重练 |
| 排查方向 | 错题复习入口（如 `startReviewWrong`）未实现或回调未绑定；或 `loadStudyNotes` 返回的错题数据结构与 `initExam` 入参不匹配 |

## 四、功能建议（P2）

### Feature-1：「问 Kimi」提示词模板升级（统一完整版）

**当前问题**：
- 部分方剂（如桂枝汤）输出结构过于简化：仅核心辨证点 + 混淆方 + 场景题
- 缺少生理学/病理生理学深度解读，与循证审计体系的价值不一致

**期望统一模板**（以通脉四逆加猪胆汁汤为例）：

```
我正在学习《伤寒论》方剂：{方名}。
原文/提纲：{source_text}
必要症：{necessary}
常见症：{common}
排除症：{excluding}
核心药物组合：{core_combo}
药物：{all_herbs}
病机：{pathology}
煎服法：{usage}
禁忌：{contraindications}

请帮我：
1. 用一句话总结此方核心辨证点；
2. 指出最容易与哪几个方混淆，并说明鉴别要点（用表格对比：方名、病机差异、症状差异、核心药物差异）；
3. 从生理学和病理生理学角度，用以下结构详细解读此方证的症状群：
   - 先给出核心链条（如：消化吸收障碍→能量底物匮乏→多器官低灌注与代偿性功能紊乱）
   - 分章节解读每个症状群（腹痛、面色、四肢、心悸、烦热等），标注：病理生理机制、为什么出现此症状、对应方药在此环节的干预作用
   - 用 Markdown 表格列出每味药物的生理学作用（药物 | 生理学作用）
   - 最后给一句话总结（生理学版）
4. 给出一道我自测用的场景题（给出患者症状描述，让我选方，并给出答案和解析）。

请用 Markdown 格式输出，便于我复制到笔记中。
```

**实现要求**：
- 所有方剂的「问 Kimi」提示词统一使用上述完整模板
- 字段从 `card.data.canonical` 动态填充，确保数据完整性
- 提示词末尾自动添加 `请用 Markdown 格式输出，便于我复制到笔记中。`
