# 右侧检索功能设计方案 · 智能搜索面板

> 在卡片列表（dashboard）右侧空白区域，添加一个智能搜索面板。用户输入方名、拼音首字母或标签，实时过滤并显示匹配结果，点击直接跳转学习页。

---

## 一、功能定位

**使用场景**：
- 用户想快速找到某个方剂卡片，不想在列表中滚动
- 用户想按标签筛选一类方剂（如"所有太阳病方"）
- 用户只记得方剂名的一部分（如"桂枝"），想快速找到所有桂枝类方
- 用户想按拼音首字母快速查找（如输入"GZT"找桂枝汤）

**核心原则**：
- **实时**：无需回车，输入即过滤
- **多维**：支持方名、拼音首字母、标签三种匹配方式
- **智能**：混合模式下，优先显示最相关的结果
- **快速**：点击结果直接跳转，无需二次确认

## 三、搜索模式与匹配规则

### 模式1：方名匹配（汉字 + 模糊匹配）

| 输入 | 匹配结果 | 匹配逻辑 |
|---|---|---|
| 桂枝 | 桂枝汤、桂枝加葛根汤、桂枝去芍药汤、桂枝麻黄各半汤... | 包含"桂枝"的所有方 |
| 麻黄 | 麻黄汤、麻黄杏仁甘草石膏汤、桂枝麻黄各半汤... | 包含"麻黄"的所有方 |
| 小柴胡 | 小柴胡汤、柴胡加芒硝汤、柴胡加龙骨牡蛎汤... | 包含"小柴胡"或"柴胡"的所有方 |
| 四逆 | 四逆汤、四逆散、通脉四逆汤、四逆加人参汤... | 包含"四逆"的所有方 |

**匹配逻辑**：
```javascript
// 按方名模糊匹配
function matchByName(query) {
  return CARDS.filter(c => c.name.includes(query) || c.formula_name.includes(query));
}
```

### 模式2：拼音首字母匹配（Pinyin Initials）

| 输入 | 匹配结果 | 匹配逻辑 |
|---|---|---|
| GZT | 桂枝汤 | 拼音首字母匹配 |
| MHT | 麻黄汤 | 拼音首字母匹配 |
| XCHT | 小柴胡汤 | 拼音首字母匹配 |
| GGT | 葛根汤 / 葛根加半夏汤 / 葛根黄芩黄连汤... | 首字母匹配 |

**匹配逻辑**：
```javascript
// 每个卡片需要添加拼音首字母字段
const pinyinMap = {
  'gui-zhi-tang': 'GZT',
  'ma-huang-tang': 'MHT',
  'xiao-chai-hu-tang': 'XCHT',
  // ...
};

function matchByPinyin(query) {
  const upper = query.toUpperCase();
  return CARDS.filter(c => {
    const pinyin = getPinyinInitials(c.id); // 从拼音首字母映射获取
    return pinyin === upper || pinyin.startsWith(upper);
  });
}
```

### 模式3：标签匹配（Tag Matching）

| 输入 | 匹配结果 | 匹配逻辑 |
|---|---|---|
| 太阳病 | 所有 tags 包含 "太阳病" 的卡片 | 精确标签匹配 |
| 解表剂 | 所有 tags 包含 "解表剂" 的卡片 | 精确标签匹配 |
| 少阳 | 所有 tags 包含 "少阳" 的卡片（如少阳病、少阳证） | 包含匹配 |
| 重证 | 所有 tags 包含 "重证" 的卡片 | 精确标签匹配 |

**匹配逻辑**：
```javascript
function matchByTag(query) {
  return CARDS.filter(c => c.tags && c.tags.some(t => t.includes(query)));
}
```

## 四、混合搜索与优先级排序

当用户输入时，系统同时运行三种匹配模式，然后**按优先级排序**显示结果。

### 优先级规则

1. **精确方名匹配**（如输入"桂枝汤"精确匹配）→ 最高优先级
2. **拼音首字母精确匹配**（如输入"GZT"精确匹配）→ 高优先级
3. **标签精确匹配**（如输入"太阳病"精确匹配）→ 中高优先级
4. **方名模糊匹配**（如输入"桂枝"匹配多个）→ 中优先级
5. **标签模糊匹配**（如输入"表"匹配"解表剂"）→ 低优先级

### 展示分组

结果按匹配类型分组展示，每组最多显示5个结果，超过显示「查看全部」：

```
🔍 搜索结果：

── 按方名匹配（3）──
  [桂枝汤] [桂枝加葛根汤] [桂枝麻黄各半汤] [查看全部→]

── 按标签匹配（8）──
  [太阳病(8)] [解表剂(5)] [风伤卫(3)]

── 按拼音匹配（1）──
  [GZT → 桂枝汤]
```

## 五、拼音首字母映射表

需要在 `formula_cards.json` 中为每个卡片添加 `pinyin_initials` 字段，或在代码中维护映射。

```json
{
  "id": "gui-zhi-tang",
  "name": "桂枝汤",
  "pinyin_initials": "GZT",
  "tags": ["太阳病", "解表剂", "风伤卫"]
}
```

**备选方案**：如果不在 JSON 中增加字段，可以在 `index.html` 中通过代码自动生成拼音首字母（从 `id` 或 `name` 映射）。

### 6.1 键盘交互

| 操作 | 行为 |

| 输入字符 | 实时过滤，显示下拉面板 |

### 7.3 新增 JS 函数

```javascript
// 拼音首字母映射（从 id 自动生成）
function getPinyinInitials(cardId) {
  const map = {
    'gui-zhi-tang': 'GZT',
    'ma-huang-tang': 'MHT',
    'ge-gen-tang': 'GGT',
    'xiao-chai-hu-tang': 'XCHT',
    'da-cheng-qi-tang': 'DCQT',
    // ... 可以动态生成
  };
  return map[cardId] || cardId.split('-').map(s => s[0].toUpperCase()).join('');
}

// 搜索处理
function handleSearch(query) {
  if (!query.trim()) {
    showSearchHistory();
    return;
  }
  
  const results = {
    name: matchByName(query),
    pinyin: matchByPinyin(query),
    tag: matchByTag(query)
  };
  
  renderSearchResults(results, query);
  saveSearchHistory(query);
}

// 渲染搜索结果
function renderSearchResults(results, query) {
  const container = document.getElementById('searchResults');
  let html = '';
  
  if (results.name.length > 0) {
    html += `<div class="search-group">
      <div class="search-group-title">按方名匹配（${results.name.length}）</div>
      ${results.name.slice(0, 5).map(c => `
        <div class="search-result-item" onclick="startCardStudy('${c.id}')">
          <span>${c.name}</span>
          <span class="search-tag-chip">${c.tags[0] || '方剂'}</span>
        </div>
      `).join('')}
      ${results.name.length > 5 ? `<div style="text-align:center;padding:4px;font-size:12px;color:var(--accent);cursor:pointer;" onclick="showAllNameResults('${query}')">查看全部 ${results.name.length} 个</div>` : ''}
    </div>`;
  }
  
  if (results.tag.length > 0) {
    const tagGroups = groupByTag(results.tag, query);
    html += `<div class="search-group">
      <div class="search-group-title">按标签匹配</div>
      ${tagGroups.map(t => `
        <div class="search-result-item" onclick="showTagCluster('${t.tag}')">
          <span>${t.tag}（${t.count}张）</span>
          <span class="search-tag-chip">标签</span>
        </div>
      `).join('')}
    </div>`;
  }
  
  if (results.pinyin.length > 0) {
    html += `<div class="search-group">
      <div class="search-group-title">按拼音匹配（${results.pinyin.length}）</div>
      ${results.pinyin.slice(0, 3).map(c => `
        <div class="search-result-item" onclick="startCardStudy('${c.id}')">
          <span>${getPinyinInitials(c.id)} → ${c.name}</span>
        </div>
      `).join('')}
    </div>`;
  }
  
  container.innerHTML = html || '<div class="search-group" style="text-align:center;color:var(--text-muted);padding:16px;">无匹配结果</div>';
  document.getElementById('searchDropdown').style.display = 'block';
}

// 搜索历史
function saveSearchHistory(query) {
  const history = JSON.parse(localStorage.getItem('search_history') || '[]');
  history.unshift(query);
  localStorage.setItem('search_history', JSON.stringify(history.slice(0, 10)));
}
```

## 十、标签体系下一步改进方向

当前标签体系的问题（用户反馈）：

1. **标签层级混乱**："太阳病"（病篇）和"解表剂"（功能）和"风伤卫"（病机）混在一起，没有分类层级
2. **标签粒度不一致**：有的标签是病名（"太阳病"），有的是症状（"汗出"），有的是功能（"解表剂"），用户搜索时难以区分
3. **标签覆盖不完整**：很多重要标签缺失（如"六经"、"表里"、"寒热"、"虚实"等中医核心辨证维度）

改进方向：
- 建立**标签分类体系**（六经、功能、病机、症状、特殊属性）
- 每个标签归属一个**分类**，搜索时按分类过滤
- 标签支持**多选交集**（如"太阳病" + "解表剂" → 同时满足两个条件的方）
