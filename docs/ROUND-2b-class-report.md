### 1.2 类方学习界面（onHerbClick 重构）

点击药名后弹窗显示：

```
🌿 柴胡（北柴胡）
├─ 类方：柴胡剂 / 清热剂 · 共 8 方
├─ 柴胡剂系列（3方）
│   ├─ 大柴胡汤  少阳阳明合病方 · 该方中 12克  [●●●●●●]
│   ├─ 小柴胡汤  少阳病主方 · 该方中 10克  [●●●●●○]
│   └─ 柴胡加龙骨牡蛎汤  少阳病 · 该方中 6克  [●●●○○○]
└─ 桂枝剂系列（2方）
    └─ 柴胡桂枝汤  太少两感方 ... [○○○○○○]

[去学习 大柴胡汤] [关闭]
```

**关键特性**：
- 按 `lineage.base_formula` 分组（类方系列）
- 每组显示前 5 个方，超过显示"还有 N 个方..."
- 每个方显示：方名、描述、该方中此药的剂量、掌握度圆点（6向量）
- 点击方卡片直接跳转学习页
- 显示别名（如「柴胡（北柴胡）」）

### 1.3 存疑标注

如果处方中的药名不在 `HERB_ALIAS_MAP` 中：
- 药名后显示 `⚠` 红色小标记
- 鼠标悬停提示："该药名未在映射表中确认，可能存在别名"

## 四、已知问题

1. **类方分组只显示前 3 组**：如果某药出现在很多不同 lineage 中，可能显示不全。但核心 10 方中，每组药通常只有 2-3 个 lineage 系列。
2. **掌握度圆点可能为 0**：如果某方还没练习过，6 个圆点都是灰色。这是预期行为。
3. **弹窗内卡片悬停效果**：用 inline onmouseover/onmouseout，在移动端无效（但弹窗主要是桌面使用）。
