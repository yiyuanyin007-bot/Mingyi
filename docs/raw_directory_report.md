## 五、数据价值与利用建议

### 5.1 按优先级排列的数据源

| 优先级 | 目录/文件 | 用途建议 |
|---|---|---|
| P0 | `annotations/倪海夏-人纪- 伤寒论.txt` | 直接提取方证、条文、剂量，作为 **experience_cards** 和 **formula_cards** 的核心来源 |

| P2 | `annotations-chm/` 的原始 CHM | 保留备份，如需重新提取可再次解压 |

### 5.2 提取技术建议

- `.txt` 文件：直接读取，按「条文编号 + 方剂名 + 症状」正则提取
- `.doc` 文件：用 Python `python-docx` 或 `antiword` 转换为文本后提取
- `.html` 文件：用 `BeautifulSoup` 批量解析，提取标题、正文、方剂名、症状描述
- `.chm` 文件：已解压，如需进一步处理可用 `chm` 工具或直接从 `extracted-chm/` 获取
