## 一、用户痛点分析

| 痛点 | 表现 | 用户自述 |
|---|---|---|
| 信息抵触 | 面对大量文字不想看，乱选 | "面对一堆文字会产生抵触心理，不想看，做题时就会乱选" |
| 类方混淆 | 症状相似，方名搞混 | 错选"桂枝去芍药汤"，正确是"大柴胡汤" |
| 记忆模糊 | 知道大概，具体记不清 | 选的和正确答案只差一字 |
| 知识盲区 | 完全没接触过 | 选了完全不相关的方 |

## 二、错因诊断模型

### 2.1 四种错因类型

| 错因 | 图标 | 典型表现 | 自动识别规则 |
|---|---|---|---|
| **搞混了** | 🤔 | 选了相近的类方 | 错误选项与正确答案 share ≥2 个相同标签（lineage） |
| **记错了** | 😵 | 选了同一个方但知识点错误 | 选了正确方但向量答错（如 0→1 的禁忌选成症状） |
| **没学过** | ❓ | 选了完全无关的方 | 错误选项与正确答案无任何 lineage/tag 交集 |
| **乱选的** | 😫 | 抵触心理，快速选 | 答题时间 < 3 秒（可记录）或用户手动选择 |

### 2.2 自动识别算法

```javascript
function autoDiagnoseMistake(answer) {
  const q = answer.question;
  const selected = answer.selected;
  const correctCard = CARDS.find(c => c.id === q.correct || c.name === q.correct);
  const selectedCard = CARDS.find(c => c.id === selected.id || c.name === selected.label);
  
  if (!selected) return 'skipped'; // 未作答
  
  // 搞混了：选了相近的类方
  if (selectedCard && correctCard) {
    const sharedTags = (selectedCard.tags || []).filter(t => (correctCard.tags || []).includes(t));
    if (sharedTags.length >= 2) return 'confused';
    
    // 是否属于同一个 base_formula lineage
    if (selectedCard.lineage?.base_formula === correctCard.lineage?.base_formula) return 'confused';
  }
  
  // 没学过：完全无关
  if (selectedCard && correctCard) {
    const sharedTags = (selectedCard.tags || []).filter(t => (correctCard.tags || []).includes(t));
    if (sharedTags.length === 0) return 'unknown';
  }
  
  // 记错了：选了同一个方但向量答错（不适用于 1→0/2→0）
  if (selectedCard?.id === correctCard?.id) return 'misremembered';
  
  // 默认
  return 'unknown';
}
```

## 三、Prompt 模板引擎

### 3.1 四种错因对应的 Prompt

#### 错因 A：搞混了（类方混淆）

```
你是中医经方学习助手。用户在做"{向量类型}"题型时，把【{方A}】和【{方B}】搞混了。

具体题目：
- 题目：{题目文本}
- 用户选择了：{方A}
- 正确答案是：{方B}

请用以下内容帮助用户区分：
1. 两方的核心差异（症状、病机、药物组成）
2. 简洁的口诀或记忆锚点
3. 临床辨别的关键要点（一句话原则）

要求：结构化输出，适合临床快速回忆。不超过400字。
```

#### 错因 B：记错了（知识点错误）

```
你是中医经方学习助手。用户在做"{向量类型}"题型时，记错了【{方名}】的【知识点类型】。

具体题目：
- 题目：{题目文本}
- 用户选择了：{错误选项}
- 正确答案是：{正确答案}

请用以下内容帮助用户记忆：
1. 解释为什么这个知识点容易记错（常见误区）
2. 给出记忆锚点（联想、口诀、图像化）
3. 补充临床运用要点（让知识变得有用）

要求：不超过300字，便于记忆。
```

#### 错因 C：没学过（知识盲区）

```
你是中医经方学习助手。用户在【{方名}】这个知识点上完全是盲区。

具体题目：
- 题目：{题目文本}
- 正确答案是：{正确答案}

请用以下内容帮用户快速入门：
1. 这个方的核心定位（一句话记住它是干嘛的）
2. 经典原文 + 关键症状（原文是最强的记忆锚点）
3. 药物组成速记（核心药组）
4. 临床应用一句话

要求：入门友好，不超过300字。用"💡"标记关键要点。
```

#### 错因 D：乱选的（抵触心理）

```
你是中医经方学习助手。用户表示这道题是"乱选"的，可能因为面对大量文字产生了抵触心理。

具体题目：
- {题目文本}
- 正确答案是：{正确答案}

请用以下内容帮用户降低心理门槛：
1. 用1-2句话提炼这个知识点的核心（不要长句）
2. 给一个有趣的临床场景（让知识变得有趣/有用）
3. 建议用户下次如何避免"乱选"心态（如：先深呼吸，先看关键词）

要求：轻松、有温度、简短。不超过150字。用"🌟"标记鼓励的话。
```

### 3.2 Prompt 生成函数

```javascript
function generateDiagnosisPrompt(answer, diagnosis) {
  const q = answer.question;
  const selected = answer.selected;
  const correctCard = getCardByAnswer(q);
  const selectedCard = CARDS.find(c => c.id === selected?.id);
  
  const templates = {
    confused: `你是中医经方学习助手...`,
    misremembered: `你是中医经方学习助手...`,
    unknown: `你是中医经方学习助手...`,
    random: `你是中医经方学习助手...`
  };
  
  return templates[diagnosis]
    .replace('{向量类型}', getVectorLabel(q.type))
    .replace('{方A}', selected?.label || '未选')
    .replace('{方B}', formatCorrectAnswer(q))
    .replace('{题目文本}', q.text)
    .replace('{方名}', correctCard?.name || '')
    .replace('{错误选项}', selected?.label || '未选')
    .replace('{正确答案}', formatCorrectAnswer(q))
    .replace('{知识点类型}', getVectorLabel(q.type));
}
```

### 5.2 艾宾浩斯复习调度算法

```javascript
const EBINGHAUS_INTERVALS = [1, 2, 4, 7, 14, 30]; // 天数

function createReviewSchedule(baseDate = new Date()) {
  const base = new Date(baseDate);
  return EBINGHAUS_INTERVALS.map(days => {
    const d = new Date(base);
    d.setDate(d.getDate() + days);
    return { date: d.toISOString().split('T')[0], done: false };
  });
}

function getDueNotes(notes) {
  const today = new Date().toISOString().split('T')[0];
  return notes.filter(note => 
    note.reviewSchedule.some(r => r.date === today && !r.done)
  );
}
```
