## 一、执行摘要

### 1.1 Bug 修复：处方药物解析

**问题**：正则表达式 `([^，。、
]{1,6}[
]+[克g])` 按"位置"匹配，导致：
- "师处方：柴胡10克，黄芩10克，**半夏10克**" → 解析出 "夏10克"（药名截断）
- "柴胡10克，黄芩10克，**10克**" → 解析出 "10克"（无药名）

**根因**：`
` 匹配任意非分隔符字符（包括"半"+"夏"中的"夏"），而不是按"已知药名"匹配。

**修复方案**：
1. 建立 **291 个已知药名库**（从 35 张卡片 herbs + 常见别名）
2. 按**药名精确匹配**：在文本中搜索每个已知药名，然后找后面的 数字+单位
3. 按**长度降序**匹配：先匹配"炙甘草"再匹配"甘草"，防止短名截取长名的前缀
4. **边界检查**：药名前后不能是中文汉字（避免匹配到别的词内部）

**结果**：
- 核心 10 方 34 个医案 → 全部解析成功（33 个 OK + 1 个 fallback）
- 平均每医案提取 10-17 味药

### 1.2 视觉规范 V1：药物呈现

**新增 CSS 类**（5 个）：

| 类名 | 作用 | 样式 |
|------|------|------|
| `.rx-herb-name` | 药名 | font-weight: 700; 下划线虚线; 点击可交互 |
| `.rx-herb-dose` | 剂量 | font-size: 12px; color: var(--text-muted) |
| `.rx-separator` | 分隔符 | "、" 灰色小字 |
| `.rx-formula-tag` | 合方标签 | 灰底彩字圆角标签，悬停反色 |
| `.rx-formula-label` | 前缀 | "合"/"加"/"减" 10px 小字 |

**前端函数修改**：
- `renderPrescription()` → 使用新 CSS 类，分隔符改为 "、"
- `renderFormulaLink()` → 使用 `.rx-formula-tag` 类，前缀 "合"
