# Skill-001: 上班了（Morning Brief）

> **触发条件**: 用户说"上班了"或"开始工作"或"同步一下"  
> **执行者**: 任何进入项目的新AI会话  
> **输出**: 今日简报（30秒读完）

---

## 一、执行流程

每次新会话启动时，按以下顺序执行：

### Step 1: 运行 session_start.py

```bash
python scripts/session_start.py
```

**作用**: 检查项目健康状态，自动验证：
- JSON合法性（formula_cards.json / source_cards.json / experience_cards.json）
- 文件完整性（关键文件是否存在）
- 临时文件清理（是否有遗留temp文件）
- 备份状态（最近备份时间）

**预期输出**: 健康报告（PASS/警告）

### Step 2: 读取 STATUS.md

```markdown
文件: docs/STATUS.md
```

**重点读取**:
- 当前阶段（当前聚焦什么）
- 今日任务标识（今天的唯一锚点）
- 活跃会话（谁在做什么）
- 阻塞项（有什么卡住了）
- 下一步推荐（P0/P1/P2任务列表）

### Step 3: 读取 对话总控看板

```markdown
文件: docs/对话总控看板.md
```

**重点读取**:
- 各对话当前状态（进行中/等待/空闲）
- 交付物清单（各对话已产出什么）
- 跨对话依赖关系（哪些对话需要交换数据）

### Step 4: 输出今日简报

**简报格式**:

```markdown
## 今日简报（2026-07-02）

### 当前阶段
{当前阶段描述}

### 今日任务标识
{今日唯一锚点}

### 活跃会话状态
- 会话A: {角色} — {状态} — {下一步}
- 会话B: {角色} — {状态} — {下一步}

### 阻塞项
- {阻塞项1}: {影响} → {解除条件}

### 推荐下一步（P0）
1. {任务1}
2. {任务2}
3. {任务3}

### 快速链接
- 状态看板: docs/STATUS.md
- 执行计划: docs/本周执行计划_SH-PLAN-20260702-001.md
- 对话总控: docs/对话总控看板.md
```
