### SKILL-001: 上班了（Morning Brief）

| 属性 | 内容 |
|------|------|
| 编号 | SKILL-001 |
| 名称 | 上班了 |
| 文件路径 | `docs/skills/SKILL_morning_brief.md` |
| 创建日期 | 2026-07-02 |
| 版本 | v1.0 |
| 状态 | 活跃 |
| 使用场景 | 新会话启动时，检查项目状态、输出今日简报 |
| 最近更新 | 2026-07-02 |

**功能描述**:
每次新会话启动时自动执行：
1. 运行 `scripts/session_start.py` → 检查项目健康状态
2. 读取 `docs/STATUS.md` → 了解当前全局状态
3. 读取 `docs/对话总控看板.md` → 了解对话协作状态
4. 输出简报：今日任务标识 + 活跃阻塞 + 下一步推荐

**触发方式**: 用户说"上班了"或"开始工作"或"同步一下"

### SKILL-002: 下班了（Evening Wrap）

| 属性 | 内容 |
|------|------|
| 编号 | SKILL-002 |
| 名称 | 下班了 |
| 文件路径 | `docs/skills/SKILL_evening_wrap.md` |
| 创建日期 | 2026-07-02 |
| 版本 | v1.0 |
| 状态 | 活跃 |
| 使用场景 | 会话结束时，归档状态、备份、验证、清理 |
| 最近更新 | 2026-07-02 |

**功能描述**:
每次会话结束时自动执行：
1. 写会话速记卡 → `logs/session_notes/S-{日期}-{NNN}.md`
2. 更新 `docs/STATUS.md` → 标记今日完成项
3. 更新 `docs/对话总控看板.md` → 更新对话状态
4. 运行 `scripts/governance.py check-json` → 验证所有JSON合法性
5. 运行 `scripts/governance.py clean-temp` → 清理临时文件
6. 输出报告：今日完成总结 + 明日计划 + 阻塞提醒

**触发方式**: 用户说"下班了"或"结束会话"或"保存进度"

### SKILL-003: 项目全景评估（Project Overview）

| 属性 | 内容 |
|------|------|
| 编号 | SKILL-003 |
| 名称 | 项目全景评估 |
| 文件路径 | `docs/skills/SKILL_project_overview.md` |
| 创建日期 | 2026-07-02 |
| 版本 | v1.0 |
| 状态 | 活跃 |
| 使用场景 | 需要全面了解项目资产、能力边界、风险点时 |
| 最近更新 | 2026-07-02 |

**功能描述**:
扫描项目资产，生成评估报告：
1. 扫描 `data/*.json` → 统计卡片/条文/病例数量
2. 扫描 `docs/` → 统计文档数量、类型分布
3. 扫描 `app/` → 统计功能模块、代码规模
4. 扫描 `scripts/` → 统计工具脚本
5. 检查六经覆盖度 → 输出短板分析
6. 检查循证审计进度 → 输出审计状态
7. 生成报告：`docs/reports/project_overview_YYYYMMDD.md`

**触发方式**: 用户说"评估项目"或"看看项目情况"或"项目全景"
