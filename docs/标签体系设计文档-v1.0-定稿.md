# 经方标签体系设计文档 v1.0 定稿

> 适用对象：经方学习系统 v8 方剂卡片详情页标签区
> 设计原则：紧凑、统一、渐变色分区、视觉引导、可点击

---

## 一、核心设计原则

| 原则 | 含义 | 设计表现 |
|------|------|---------|
| **紧凑** | 不额外占用垂直空间，信息密度最大化 | 所有标签在一行 `flex-wrap` 内流动，间距仅 6px |
| **统一** | UI 元素与现有系统风格一致 | 复用 `.tag` 基础样式（`padding: 2px 8px; border-radius: 10px; font-size: 11px`） |
| **渐变色** | 颜色柔和过渡，不刺眼 | 第一层标签用带渐变背景的 tag，第二层用浅色背景 + 彩色边框，第三层用纯色强调 |
| **分区** | 三层标签自然分隔，不混淆 | 层次之间用 **8px 间距** 分组（第一层→第二层 gap: 8px; 第二层→第三层 gap: 8px） |
| **视觉引导** | 用户扫视时一眼识别层次 | 第一层：六经颜色转盘（背景色）→ 第二层：浅色边框（区分类型）→ 第三层：动态异常（圆点+文字） |
| **可点击** | 所有标签复用现有筛选逻辑 | 点击任意标签 → `showTagCluster(tag)` 进入同类卡片视图 |

## 二、三层标签定义

### 第一层：分类维度（固定，每卡必显）

**作用**：定位方剂在中医体系中的坐标，形成长期记忆锚。

| 标签类型 | 数量 | 示例 | 来源字段 |
|---------|------|------|---------|
| 六经归属 | 6 | 太阳病、阳明病、少阳病、少阴病、厥阴病、太阴病 | `tags` 匹配六经名 |
| 方剂类型 | 11 | 解表剂、攻下剂、和解剂、温里剂、清热剂、补益剂、祛湿剂、理血剂、固涩剂、驱虫剂、祛痰剂 | `tags` 匹配类型名 |

**呈现规则**：
- 紧凑排列，无额外标题
- 六经标签用**颜色转盘背景**（见第 4 节）
- 类型标签用**中性渐变背景**（灰→深灰）

### 第二层：内容标签（从卡片内容提取，每卡 2-5 个）

**作用**：连接症状、病机、药对与卡片，支持多维检索。

| 子层 | 数量 | 示例 | 提取来源 |
|------|------|------|---------|
| 核心症状 | 25 | 汗出、无汗、发热、恶寒、头痛、身痛、喘咳、呕吐、下利、便秘、烦躁、心悸、腹满痛、小便不利、口渴、项背强、厥逆、不眠、胸胁满、谵语、瘀血、水饮、黄疸、蛔虫、表郁 | `canonical.symptom_profile` |
| 核心病机 | 18 | 表虚、表实、表郁、里热、腑实、少阳枢机、阳虚、阴虚、阴阳两虚、寒热错杂、水饮内停、瘀血内阻、湿热蕴结、肝气郁结、脾虚湿困、营卫不和、太少两感、阳明少阳 | `canonical.pathology` 文字匹配 |
| 核心药对 | 30 | 桂芍、麻桂、柴芩、附姜、苓桂、麻杏、石膏知母、桃核、抵当、归桂、芍甘、栀豉、连胶、乌头、参姜、苓术、附术、茵栀、黄白、猪胶、麻子、大黄硝、柴龙、苓姜、大朴、硝黄、赤姜、桂草、桂附、苓泻 | `core_combinations` 映射（见第 5 节） |
| 特殊属性 | 20 | 太少两感、表里双解、寒热错杂、上热下寒、阳郁厥逆、戴阳、脾约、蓄水、蓄血、水逆、蛔厥、阴盛格阳、亡阳虚脱、气阴两伤、心肾不交、血虚寒厥、风湿痹痛、阳虚外感、误下后、急救回阳 | `tags` 匹配特殊属性名 |

**呈现规则**：
- 所有第二层标签用**浅色背景 + 细边框**，不同子层用**边框颜色区分**：
  - 症状：边框 `#e0e0e0`（浅灰）
  - 病机：边框 `#e8d5c0`（浅棕）
  - 药对：边框 `#d0d0d0`（银灰）
  - 特殊：边框 `#e0c870`（浅黄）
- 标签内文字统一用 `color: var(--text-secondary)`（`#616161`），保持可读性

### 第三层：动态标签（异常才显示，每卡 0-1 个）

**作用**：基于学习数据（mastery 向量）实时反馈，只提示需要关注的状态。

| 动态标签 | 触发条件 | 视觉样式 |
|---------|---------|---------|
| 薄弱：X→Y | 某向量连续 3 次错误 | 红色圆点 🔴 + 红色文字 |
| 已掌握 | 全部向量 ≥ 3 级 | 绿色圆点 🟢 + 绿色文字 |
| 易混：方名 | 与某方频繁混淆（考试互选） | 橙色圆点 🟠 + 橙色文字 |
| 高频错题 | 同一向量累计错 ≥ 5 次 | 红色圆点 🔴 + 红色文字 |

**呈现规则**：
- 只有异常状态才显示，正常状态**完全隐藏**（不占用空间）
- 显示在标签行**最右侧**，用 `margin-left: auto` 推过去
- 用圆点 + 文字，比边框 tag 更醒目

## 四、颜色转盘与六经辨证

### 六经在转盘上的方位（基于《伤寒论》传变顺序）

```
          太阳病（🟠 橙）
             ↑
    太阴病 ←  ·  → 阳明病（🔴 红）
    （🟡 黄）      （🔴 红）
             ↓
          少阴病（🔵 蓝）
             ↓
    厥阴病 ←  ·  → 少阳病（🟢 绿）
    （🟣 紫）      （🟢 绿）
```

**传变顺序**：太阳 → 阳明/少阳 → 太阴 → 少阴 → 厥阴（或直中太阴/少阴）

**颜色选择逻辑**：

| 六经 | 属性 | 颜色 | 渐变方向 | 心理联想 |
|------|------|------|---------|---------|
| 太阳 | 表、阳、热 | 🟠 橙 | 白→橙 | 日出、表热、升发 |
| 阳明 | 里、大热、燥 | 🔴 红 | 白→红 | 大热、白虎、极阳 |
| 少阳 | 半表半里、枢机 | 🟢 绿 | 白→绿 | 春生、枢转、生机 |
| 太阴 | 里阴、湿、脾 | 🟡 黄 | 白→黄 | 土、中央、湿化 |
| 少阴 | 心肾、水火 | 🔵 蓝 | 白→蓝 | 寒化、水、沉潜 |
| 厥阴 | 阴尽阳生、寒热错杂 | 🟣 紫 | 白→紫 | 阴极转阳、紫气东来 |

**渐变实现**：所有六经标签统一用 `linear-gradient(135deg, white 0%, 主题色 100%)`，从纯白到主题色的 135° 渐变。这样：
- 标签有**立体感**（左上亮、右下暗）
- 与系统白色背景**自然融合**
- 多标签并排时形成**柔和色带**，不刺眼

### 映射 6：第三层（动态）

从 `card.mastery` 向量计算：

```js
function getDynamicTags(card) {
  const tags = [];
  const mastery = card.mastery || {};
  
  // 检查薄弱向量
  Object.entries(mastery).forEach(([vec, data]) => {
    if (data.streak_wrong >= 3) {
      tags.push({ type: 'weak', text: `薄弱：${vec}` });
    }
  });
  
  // 检查已掌握
  const allMastered = Object.values(mastery).every(d => d.level >= 3);
  if (allMastered) tags.push({ type: 'master', text: '已掌握' });
  
  // 检查易混淆（从错题记录中提取）
  // 从 localStorage 的错题本读取
  
  return tags;
}
```

## 六、实施计划

### 阶段 1：前端 JS 映射（立即可用，不改动 JSON）

1. 在 `index.html` 中建立 `TAG_SYSTEM` 常量（六经/类型/症状/病机/药对/特殊 的映射表）
2. 修改 `renderLearnPage()` 中标签渲染逻辑，从 `card.tags` 和 `card.canonical` 提取并分类
3. 添加 `getDynamicTags()` 函数，从 mastery 向量生成动态标签
4. 所有标签绑定 `onclick="showTagCluster('${tag}')"`（复用现有逻辑）

### 阶段 2：JSON 数据治理（后续逐步完成）

1. 为每张卡片添加 `layer1_tags`（六经+类型）、`layer2_tags`（症状+病机+药对+特殊）字段

3. 标准化药对标签（从 `core_combinations` 自动映射）

### 阶段 3：视觉编码优化（可选）

1. 在设置中增加「高对比度模式」开关（色盲友好）
2. 动态标签增加「呼吸灯」效果（薄弱向量红点闪烁）
