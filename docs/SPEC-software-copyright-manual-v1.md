## 一、软件概述

### 1.1 开发背景

中医经方学习长期面临三大核心痛点：一是学了记不住，记忆痕迹不巩固；二是记住了不会用，从经典条文到临床开方存在断裂；三是用了不知道对不对，缺乏即时反馈和诊断工具。现有中医学习类应用多以资料浏览为主，缺乏基于认知科学的训练机制，无法将《伤寒论》等经典著作中的方证知识转化为可测量的临床能力。

### 1.2 开发目的

"明医成长录"（经方学习系统 v9）以"建立经方认知能力的可训练、可测量、可进化系统"为核心目标，不是做一个简单的伤寒论资料浏览工具，而是构建一个认知训练器——让学习者通过系统化的多向量训练，建立从"方名→症状→药组→煎服法→禁忌"的多向映射能力，最终实现经典条文到临床方证对应思维的完整闭环。

### 1.3 软件定位

- **软件类型**：Web 应用（渐进式 Web App，PWA）
- **运行环境**：浏览器（Chrome / Safari / Edge / Firefox 等现代浏览器）
- **适用平台**：桌面端（Windows / macOS / Linux）及移动端（iOS / Android）
- **用户对象**：中医临床学习者、经方爱好者、中医专业学生及临床医师

## 二、功能模块说明

本软件由 9 大 UI 组件模块、6 大业务服务模块、4 大工具模块及 1 个状态管理模块组成，共 22 个 JavaScript 源文件（4,780 行）、2 个 CSS 样式文件（1,793 行），总代码量约 6,573 行。软件内置结构化数据包括：方剂卡片 99 张、原文条文 398 条、标准化病人（SP）病例 106 例、临床医案 3 张。

### 2.1 核心功能模块

#### 模块一：卡片仪表盘（CardList）

- **功能描述**：作为软件首页，展示全部方剂卡片，支持多维度检索与标签聚类。
- **子功能**：
  - 方名、拼音首字母、标签关键词搜索
  - 六经分类标签快速筛选（太阳病、阳明病、少阳病、太阴病、少阴病、厥阴病）
  - 卡片掌握状态可视化（已掌握 / 正在学习 / 已遗忘 / 未知）
  - 卡片列表展示，含方剂名、描述、标签、核心药组摘要

#### 模块二：学习视图（LearnView）

- **功能描述**：单张方剂卡片的深度学习页面，是知识输入的核心入口。
- **子功能**：
  - 方剂基本信息展示（名称、角色、描述、来源篇章）
  - 症状谱系（必要症状、常见症状、排除症状）
  - 核心药物组合与剂量展示
  - 煎服法与禁忌说明
  - 核心药对解析与剂量换算
  - 关联条文原文面板（SourcePanel）一键展开，自动关联当前方剂对应的《伤寒论》原文
  - 经验医案解锁与阅读
  - 类方对比标签

#### 模块三：考试引擎（ExamView + ExamService）

- **功能描述**：软件的核心训练机制，基于"六向量掌握度模型"生成针对性练习题。
- **子功能**：
  - **六向量出题**：覆盖 6 个认知向量——方名→症状、症状→方名、方名→核心药组、核心药组→方名、方名→禁忌、方名→煎服法
  - **三种训练模式**：
    - 单卡练习：针对某一张方剂卡片的 6 向量逐一练习
    - 类方考试：对比相似方剂，强化鉴别诊断能力
    - 模拟考试：随机生成综合试卷
  - **智能选项生成**：基于卡片数据自动生成 4 个干扰项，确保选项之间具有临床鉴别意义（如类方之间的症状重叠），并自动校验选项唯一性
  - **即时反馈**：答题后立即显示正确/错误，并标注正确答案，支持颜色反馈（绿/红）
  - **答案回溯**：支持上一题/下一题导航，已答题目可修改答案
  - **全局键盘支持**：支持键盘快捷键切换题目

#### 模块四：每日复习（Daily Review）

- **功能描述**：基于掌握度状态和间隔重复算法（SRS）生成每日复习任务。
- **子功能**：
  - 自动计算当日应复习的向量（到期复习项）
  - 弱项优先推荐（优先复习掌握度低的向量）
  - 生成 5 题复习试卷
  - 复习完成后更新掌握度状态

#### 模块五：错题本（WrongBookView）

- **功能描述**：记录用户全部答错记录，支持错题回顾与针对性重练。
- **子功能**：
  - 错题列表展示（按时间倒序）
  - 错题详情查看（题目、正确答案、用户错误选择）
  - 错题删除
  - 一键问 Kimi：生成针对性的 AI 辅助分析 prompt，帮助用户理解错误原因

#### 模块六：统计分析（StatsCharts + StatsService）

- **功能描述**：多维度学习数据可视化，帮助用户了解自己的学习进度和薄弱点。
- **子功能**：
  - 六经掌握度雷达图（六经雷达图）：直观展示太阳、阳明、少阳、太阴、少阴、厥阴六经的掌握度分布
  - 学习曲线趋势图：展示累计答题数、正确率、掌握向量数随时间变化的趋势
  - 掌握度分布柱状图：展示已掌握 / 正在学习 / 已遗忘 / 未知的向量数量分布
  - 选项选择统计：记录每个选项的历史选择次数，辅助识别"惯性错误"
  - 薄弱向量分析：自动识别用户掌握度最低的向量和方剂
  - 今日学习简报：当日答题数、正确数、正确率、新增掌握向量数

#### 模块七：标准化病人（SP）训练

- **功能描述**：基于标准化病人（SP）病例的模拟问诊训练，将经典条文转化为临床场景。
- **子功能**：
  - SP 病例列表浏览（106 例结构化病例）
  - 病例详情展示：患者主诉、症状、舌象、脉象、人格特征
  - 模拟问诊交互：有限问诊次数内通过提问缩小辨证范围
  - 方证匹配评估：用户选择方剂后，系统评估与病例标准答案的匹配度

#### 模块八：检索引擎（Search + RetrievalEngine）

- **功能描述**：全文检索与智能关联，支持从症状反推方剂、从药物反推方剂等多路径检索。
- **子功能**：
  - 方名、拼音首字母、症状关键词、药物名称全文检索
  - 检索历史保存与快速复用
  - 基于症状表达索引的多路径检索（从症状→方剂、从药组→方剂）
  - 检索结果按相关度排序

#### 模块九：掌握度管理（MasteryService）

- **功能描述**：六向量掌握度状态机的核心计算与维护。
- **子功能**：
  - 六向量状态跟踪：每个方剂的 6 个向量独立记录状态（已掌握 / 正在学习 / 已遗忘 / 未知）
  - 下次复习时间计算：基于答题表现和间隔重复算法动态计算
  - 薄弱向量识别：自动计算全量向量的覆盖度和薄弱点
  - 分类覆盖度分析：按六经篇章统计各向量的掌握情况

## 三、技术特点

### 3.1 软件架构

本软件采用**纯前端单页应用（SPA）架构**，无后端服务、无数据库服务器，所有业务逻辑、数据处理和用户状态均在浏览器端完成。核心架构分为四层：

1. **表现层**：9 个独立 UI 组件，负责页面渲染与用户交互
2. **状态层**：AppStore 订阅/发布模式的状态管理中心，统一维护页面路由、考试状态、答题记录
3. **服务层**：6 个业务服务模块，封装数据加载、出题、判分、掌握度计算、统计、检索等核心业务逻辑
4. **数据层**：内置结构化 JSON 数据集（方剂卡片、原文条文、SP 病例、医案），通过 fetch 加载

### 3.2 核心算法与技术创新点

#### （1）六向量认知映射模型

软件独创性地将经方学习分解为 6 个双向认知向量：
- 方名→症状（0→1）：从方剂名推导出对应的症状谱系
- 症状→方名（1→0）：从症状组合反推对应方剂
- 方名→核心药组（0→2）：从方剂名推导出核心药物组合
- 核心药组→方名（2→0）：从药物组合反推方剂名
- 方名→禁忌（0→contra）：掌握方剂的禁忌症
- 方名→煎服法（0→usage）：掌握方剂的服用方法

每个向量独立追踪掌握状态，形成"多向映射"而非"单向记忆"的训练机制，这是区别于传统中医学习类应用的核心创新。

#### （2）基于间隔重复（SRS）的掌握度状态机

每个向量具有独立的状态机：未知 → 正在学习 → 已掌握 → 已遗忘（可循环）。状态转换由答题正确率、连续正确次数、遗忘半衰期等参数驱动，下次复习时间动态计算，实现个性化的间隔重复调度。

#### （3）智能干扰项生成算法

出题时不是随机抽取错误选项，而是从"同篇章、同类别、相似症状谱"的类方中选取干扰项，确保每个错误选项都具有临床鉴别意义。例如：出题"桂枝汤的必要症状"时，干扰项会从麻黄汤、葛根汤等太阳病类方中选取具有部分症状重叠的选项，从而训练用户的鉴别诊断能力。

#### （4）症状表达索引与多路径检索

建立从症状关键词到方剂、从药物到方剂的双向索引，支持用户以临床视角（"我遇到一个发烧、恶寒、脉浮的患者"）反向检索可能对应的方剂，打破传统"从方名到症状"的单向学习模式。

## 五、使用说明

### 5.1 软件启动

**方式一：在线访问**
1. 使用浏览器打开部署地址（如 `https://example.com`）
2. 首次加载后，软件自动缓存核心资源，支持离线访问
3. 浏览器地址栏出现"安装到主屏"提示时，可点击安装为 PWA 应用

**方式二：本地开发/预览**
1. 进入软件目录，执行 `npm install` 安装依赖
2. 执行 `npm run dev` 启动开发服务器
3. 浏览器访问 `http://localhost:8100`

### 5.2 核心使用流程

#### 流程一：方剂学习（知识输入）
1. 进入软件首页（卡片仪表盘），浏览或搜索目标方剂
2. 点击方剂卡片，进入学习视图
3. 阅读症状谱、药物组合、煎服法、禁忌等完整信息
4. 点击下方"条文"按钮，展开关联的《伤寒论》原文面板
5. 阅读完成后，点击"开始测试"进入练习模式

#### 流程二：六向量训练（能力输出）
1. 在学习视图或卡片列表中点击"开始测试"
2. 选择训练模式：单卡练习 / 类方考试 / 模拟考试
3. 逐题作答，每题选择答案后系统自动判断正误并显示反馈
4. 支持键盘左右方向键切换题目，上下方向键选择选项
5. 完成全部题目后，查看练习总结（正确率、薄弱点分析）

#### 流程三：每日复习（间隔重复）
1. 点击首页顶部"今日复习"按钮
2. 系统自动生成基于 SRS 算法的 5 题复习试卷
3. 完成答题，系统更新各向量的掌握状态
4. 答错的题目自动加入错题本

#### 流程四：错题回顾（查漏补缺）
1. 点击首页"错题本"按钮
2. 查看全部历史错题，按时间倒序排列
3. 点击错题查看详情，可一键生成"问 Kimi"的 AI 分析提示词
4. 可删除已掌握的错题

#### 流程五：统计分析（进度追踪）
1. 点击首页"统计"按钮
2. 查看六经雷达图，了解六经篇章的掌握均衡度
3. 查看学习曲线，追踪长期学习趋势
4. 查看掌握度分布，识别"正在学习"和"已遗忘"的向量

#### 流程六：SP 病例训练（临床模拟）
1. 进入 SP 病例列表，选择目标病例
2. 阅读患者主诉、症状、舌脉信息
3. 进行模拟问诊（有限次数内提问）
4. 选择辨证结论和方剂，查看系统评估结果

### 5.3 数据安全与隐私

- 所有用户数据（学习进度、掌握度、错题、统计）仅存储在用户本地浏览器的 localStorage 中
- 不上传至任何服务器，无需注册登录，无需提供个人信息
