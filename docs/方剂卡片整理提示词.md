我正在构建一套《伤寒论》经方学习系统，目前需要你对 63 张方剂卡片的数据进行整理和优化。

## 一、项目背景
- 系统基于刘渡舟、胡希恕两位注家的讲解，配合条文原文和个人总结
- 卡片数据格式为 JSON，包含 `data.canonical`（方剂核心信息）、`source_annotations`（条文+注家讲解）等字段
- 当前 63 张卡片的基础信息（方名、药味、剂量、病机、煎服法、禁忌）已完整，但注家讲解和个人总结大量缺失

## 三、整理要求

### 3.1 对于每张卡片，请提供以下内容

#### A. 条文原文（text）
- 根据该方剂的伤寒论条文，提供原文
- 格式："太阳病，xxx，xxx 主之。"
- 如果有多条相关条文，按编号列出

#### B. 刘渡舟讲解（annotations.刘渡舟）
- 基于刘渡舟的《伤寒论诠解》风格
- 重点：辨证思路、症状分析、病机推导、临床要点
- 长度：100-200 字，精炼但完整

#### C. 胡希恕讲解（annotations.胡希恕）
- 基于胡希恕的《伤寒论讲座》风格
- 重点：方证对应、六经辨证、与临床的结合
- 长度：100-200 字，精炼但完整

#### D. 个人总结（annotations.个人总结）
- 综合两位注家的核心观点，提炼临床使用要点
- 包含：辨证要点、核心症状、使用时机、注意事项
- 长度：80-150 字，便于临床快速回忆

#### E. 精炼描述（desc）
- 将现有的简短描述（如"太阳中风主方"）扩展为 20-30 字
- 格式："【六经归属】+【核心病机】+【临床定位】"
- 示例："太阳中风表虚证主方，营卫不和，汗出恶风，桂枝芍药调和营卫"

### 3.2 数据来源优先级
1. 刘渡舟《伤寒论诠解》原文（或基于其核心观点）
2. 胡希恕《伤寒论讲座》原文（或基于其核心观点）
3. 《伤寒论》原文条文
4. 中医经典教材（如《方剂学》）
5. 个人临床经验总结（最后补充，不作为主要依据）

### 3.3 输出格式

对每张卡片，请按以下 JSON 格式输出：

```json
{
  "card_id": "卡片ID",
  "card_name": "方剂名",
  "desc": "扩展后的精炼描述（20-30字）",
  "source_text_ids": ["条文ID"],
  "references": [
    {
      "article_number": "第X条",
      "text": "条文原文",
      "annotations": {
        "刘渡舟": "刘渡舟讲解内容",
        "胡希恕": "胡希恕讲解内容",
        "个人总结": "个人总结内容"
      }
    }
  ]
}
```

## 四、特别注意事项
1. **不要编造条文**：条文原文必须基于《伤寒论》原文，不确定时标注"待查证"
2. **注家讲解要区分风格**：刘渡舟重辨证，胡希恕重方证，不要混为一谈
