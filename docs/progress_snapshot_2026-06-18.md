| 心流保护 | 考完试 → 快速点标签 → 静默保存 → 继续看其他错题 → 无弹窗中断 |

**验证结果**：浏览器注入测试通过 — 点击诊断后 `notes` 从 0→1，modal 未打开。

### 4. `showModal` 参数错误修复（SH-20260618-032）

**Bug 现象**：弹窗只显示标题字符串，没有内容区域。

**根因**：`showModal(contentHtml, className)` 只有 2 个参数，但 3 处调用传了 5 个参数，导致 `prompt` 被当成 `className` 传入。

| 修复位置 | 函数 |
|---|---|
| 考试结果页 | `askKimiForWrong()` |
| 今日复习/错题本 | `askKimiFromNote()` |
| 条文面板 | `askKimiSource()` |

**修复方式**：统一拼接完整 HTML 字符串（含 `modal-title` + `modal-body` + `modal-actions`）再传入 `showModal`。

**验证结果**：浏览器注入测试通过 — 弹窗正确显示 Prompt 内容 + 标题 + 按钮。

## 五、今日心流优化总结

| 优化前 | 优化后 |
|---|---|
| 错题 → 点击诊断 → 弹大窗（Prompt + textarea + 保存按钮）→ 关闭 → 继续下一题 | 错题 → 点击诊断 → **Toast 闪一下** → 继续下一题 |
| 想深度学习必须当场做完弹窗全部流程 | 标记先存着，后续去「今日复习」或「错题本」→ **点击「🤖 问Kimi」** → 弹出 Prompt |
| 错题 > 3 时逐个弹窗，极度烦躁 | 错题 > 3 时显示「🏷️ 批量标记」→ 一键搞定 |

**核心原则**：打断越少，心流越长。做题时只做题，学习时只学习。
