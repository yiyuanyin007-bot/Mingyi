## 五、工作边界红线（与条文系统划分）

### 5.1 我方剂数据系统（当前对话）职责

| 职责 | 边界内 | 边界外 |
|---|---|---|
| **数据范围** | `data/formula_cards.json` 的卡片数量扩展 | `data/source_cards.json` 的条文内容 |
| **核心目标** | 让方剂卡片数量覆盖《伤寒论》96方 | 条文讲解、原文校对、注释撰写 |
| **输出物** | 新增卡片 JSON（含 id, name, formula_name, role, desc, tags, source_chapter, source_text_ids, lineage, data.canonical, experience_ids, references 框架） | 条文摘要、刘渡舟/胡希恕讲解、医案内容 |
| **资料处理** | 确认本地资料是否齐全，标记资料缺口 | 从资料中提取条文讲解内容 |
| **协作方式** | 卡片制好后，通知条文系统补充 `source_annotations` | 不直接修改 `source_cards.json` |

### 5.2 条文系统（另一个对话）职责

| 职责 | 内容 |
|---|---|
| **数据范围** | `data/source_cards.json` + `data/formula_cards.json` 中的 `references.source_annotations` |
| **核心目标** | 为每张卡片补充条文讲解（200字摘要 + 完整展开内容） |
| **输出物** | 条文讲解 JSON（含 title, source, summary 200字, full_text） |
| **触发条件** | 方剂系统通知"XX方卡片已创建，请补充条文讲解" |
| **禁止行为** | 修改卡片结构、新增卡片、删除卡片 |

### 5.3 协作流程

```
方剂系统（当前对话）        条文系统（另一个对话）
      |                              |
      |  1. 创建新卡片 JSON            |
      |------------------------------>|
      |                              |
      |                    2. 补充条文讲解
      |                              |
      |  3. 确认卡片完整，登记CHANGELOG |
      |<------------------------------|
      |                              |
      |  4. 通知操作系统对话更新UI     |
      |------------------------------>|
```
