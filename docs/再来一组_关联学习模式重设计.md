# 「再来一组」关联学习模式重设计 · 认知神经科学版

> 基于用户反馈：当前设计缺乏**题型间关联**和**明确题量目标**，导致学习碎片化、无方向感。本文档重新设计，让每个"再来一组"都是一次结构化的**方剂深度关联学习**。

---

## 一、用户核心需求拆解

### 需求1：题型之间要有关联

**当前问题**：`generateVariantQuestion` 只会在同一向量（如 0→1）内部换表述方式，比如：
- 第一轮：「桂枝汤必要症状包括哪些？」
- 第二轮：「以下哪组症状是桂枝汤的必见症？」

**本质**：同一知识点的**同一方向**反复练习，大脑形成的是"单向提取通路"。临床开方时需要**症状→方名**的反向提取，当前设计没有训练这种双向关联。

**正确理解**：一个方剂是一个**知识节点**，它的 6 个向量是这个节点的 6 个属性维度。学习一个方剂，不是分别掌握 6 个独立技能，而是建立"症状-方名-药组-禁忌-煎服法"的**完整概念网络**。

### 需求2：明确要学多少题

**当前问题**：用户点击「再来一组」后，不知道这一轮有多少题、来自哪些方、进度如何。这产生**认知不确定性焦虑**，降低学习动机。

**正确理解**：每一轮应该有明确的**结构声明**：
> 「本轮 8 题，来自 3 个薄弱方，每个方 2-3 个向量」

让用户知道"我在系统地攻克第3个方"，而不是"我不知道还要做多少题"。

## 二、认知神经科学解读

### 解读1：双向编码与交叉映射（Bidirectional Coding & Cross-Mapping）

**神经机制**：
海马体的 **模式完成（Pattern Completion）** 和 **模式分离（Pattern Separation）** 是记忆提取的两大机制。当你从"方名→症状"（0→1）时，大脑走的是"概念→特征"的**扩散激活**通路；当你从"症状→方名"（1→0）时，走的是"特征→概念"的**模式完成**通路。这两条通路在神经层面激活的是**不同的突触连接**。

**关键研究**：
- McClelland et al. (1995) 的互补学习系统理论：海马体负责快速绑定不同维度的信息，如果两个维度从未在同一时间窗口内被共同激活，它们之间无法形成稳定的神经联结。
- 这意味着：**如果用户只练 0→1，不练 1→0，那么症状和方名之间的神经通路是不完整的**。临床中看到症状时，想不起来方名。

**设计启示**：
同一方剂的不同向量必须在**同一学习轮次**中共同出现，才能让大脑建立"方剂概念网络"。

---

### 解读2：Hebbian 关联学习（"Neurons that Fire Together, Wire Together"）

**神经机制**：
Hebb (1949) 法则：如果两个神经元同时激活，它们之间的突触连接会增强。在中医学习中：
- "桂枝汤"这个神经元
- "汗出、恶风"这个神经元
- "桂枝、芍药、甘草、生姜、大枣"这个神经元
- "禁忌：表实无汗"这个神经元

只有当这些神经元在**短时间内被相继激活**（within 1-2 分钟的注意力窗口），它们之间才会形成稳定的联结。如果今天练 0→1，明天练 1→0，后天练 0→2，这些神经元从未在同一时间窗口内共同激活，关联就很弱。

**设计启示**：
一个轮次中，**同一方剂的 2-3 个向量题目应该连续出现**（或至少在同一轮中），让大脑建立"症状-方名-药组"的 Hebbian 联结。

---

### 解读3：预期误差与多巴胺驱动学习（Prediction Error & Dopaminergic Learning）

**神经机制**：
Schultz (1997) 的多巴胺神经元研究：当实际结果与预期一致时，多巴胺释放；当不一致时，产生**预测误差（Prediction Error）**，驱动学习和记忆更新。

在中医学习中的应用：
- 用户做 0→1 题：「桂枝汤的必要症状是汗出、恶风」（激活预期）
- 紧接着做 1→0 题：「患者出现汗出、恶风，选何方？」（验证预期）
- 如果用户正确推出「桂枝汤」→ 预期一致 → 多巴胺释放 → 强化联结
- 如果用户选错 → 预测误差 → 注意力聚焦 → 深度加工

**关键**：这种"预期-验证"的循环必须在**同一轮次**中发生，而不是跨轮次。跨轮次时，用户已经忘了上一轮的预期。

**设计启示**：
同一方剂的多个向量题目应该**相邻排列**，形成"提出假设→验证假设"的认知闭环。

---

### 解读4：目标设定效应与进度可视化（Goal-Setting Theory & Progress Visualization）

**认知机制**：
Locke & Latham (1990) 的目标设定理论：明确、具体、有挑战的目标能提升任务坚持性和表现。不确定的题量会产生**认知不确定性焦虑（Cognitive Uncertainty Anxiety）**，降低工作记忆资源，影响学习效果。

在神经层面：
- 进度条/计数器提供**完成感（Completion Gratification）** → 触发多巴胺释放
- 明确的"还剩3题" → 降低杏仁核的焦虑反应 → 释放前额叶资源用于学习
- 分段目标（如"第2个方，3/3向量"）→ 提供即时成就反馈，维持动机

**设计启示**：
每一轮必须有明确的**结构声明**和**实时进度指示**，让用户始终知道"我在哪、还有多少、目标是什么"。

---

### 解读5：认知负荷理论的元素交互性（Element Interactivity）

**认知机制**：
Sweller (1988) 的认知负荷理论：当学习材料中的元素需要同时被理解时，元素交互性（Element Interactivity）决定了外在认知负荷。如果元素之间没有关联，用户需要分别记忆，负荷高；如果元素关联紧密，用户可以通过关系推理，负荷低。

在中医方剂中：
- 桂枝汤的症状（汗出、恶风）和药组（桂枝、芍药）是**高交互性**元素——它们共同构成"营卫不和"这个病机概念
- 把「桂枝汤的症状」和「桂枝汤的药组」放在同一轮中，用户可以通过**关系推理**降低记忆负荷：「桂枝配芍药调营卫，所以症状是营卫不和的表现」

**设计启示**：
同一方剂的多个向量放在同一轮中，不是增加负荷，而是**通过关联推理降低负荷**。

## 三、新设计方案：「一题多向」关联学习模式

### 核心概念：方剂节点 × 向量维度

把每个方剂看作一个**知识节点**，6 个向量是节点的 6 个属性维度。一轮学习不是随机抽题，而是**选择若干薄弱节点，对它们的多个维度进行深度关联学习**。

```
本轮结构声明（结果页显示）：
┌────────────────────────────────────────────┐
│  🎯 再来一组：结构化学法                      │
│                                             │
│  本轮 8 题，来自 3 个薄弱方                  │
│  每个方 2-3 个向量，建立完整概念网络         │
│                                             │
│  📋 方单：                                  │
│  ① 桂枝汤（0→1 → 1→0 → 0→2）              │
│  ② 麻黄汤（1→0 → 0→1）                    │
│  ③ 小柴胡汤（0→2 → 2→0）                  │
│                                             │
│  [开始这一组]                                │
└────────────────────────────────────────────┘
```

### 题组生成算法

```
输入：上一组 questions[] + answers[]
输出：新题组 newQuestions[]（结构化数组，含分组信息）

算法：

1. 识别薄弱方（从错题中提取 cardId）
   按错题数排序，取前 N 个（N = min(错题方数, 3)）
   为什么取3个？工作记忆的"4±1"限制（Cowan, 2001），3个方是最佳认知负荷

2. 为每个薄弱方生成 2-3 个向量题目
   规则：
   - 必包含用户上次答错的向量（纠错）
   - 必包含一个**反向向量**（如果上次错0→1，这次给1→0）
   - 可选一个**药组向量**（0→2 或 2→0，建立症状-药组关联）
   
   例：用户上次桂枝汤 0→1 错了
   → 生成：
     题1: 桂枝汤 0→1（直接纠错，换表述）
     题2: 桂枝汤 1→0（反向验证，症状→方名）
     题3: 桂枝汤 0→2（关联药组，加深理解）

3. 题组排列："一题多向"模式
   不是随机打散，而是**同一方的多题相邻排列**：
   
   桂枝汤 0→1
   桂枝汤 1→0    ← 反向验证
   桂枝汤 0→2    ← 药组关联
   麻黄汤 1→0
   麻黄汤 0→1    ← 反向验证
   小柴胡汤 0→2
   小柴胡汤 2→0  ← 反向验证
   小柴胡汤 0→1  ← 症状关联

   为什么相邻？Hebbian 法则：同一方的不同维度在短时记忆内相继激活，形成稳定联结

4. 总题量计算
   题量 = Σ(每个方的向量数)
   如果超过 10 题，截断到 10 题（避免认知超载）
   如果不足 5 题，补充已掌握方的间隔复习题

5. 进度数据结构
   每题附带：
   {
     ...question,
     roundInfo: {
       totalCards: 3,        // 本轮共3个方
       totalQuestions: 8,    // 本轮共8题
       cardIndex: 0,         // 这是第0个方（桂枝汤）
       vectorIndex: 0,       // 这是该方第0个向量
       cardName: '桂枝汤'    // 方便UI显示
     }
   }
```

## 四、实施改动方案（最小闭环）

### 改动1：题组生成引擎重构（核心）

**当前**：`startRetrievalRound()` 按 60/40 比例随机抽题，同一向量变异表述
**改为**："一题多向"关联学习模式

**新算法**：
```javascript
function startRetrievalRound() {
  // 1. 提取薄弱方（从错题）
  const weakCardIds = extractWeakCards(state.exam.answers);
  
  // 2. 取前3个薄弱方（工作记忆限制）
  const selectedCards = weakCardIds.slice(0, 3);
  
  // 3. 为每个方生成2-3个向量题目
  const questions = [];
  selectedCards.forEach((cardId, cardIdx) => {
    const card = getCard(cardId);
    const wrongVectors = getWrongVectors(cardId, state.exam.answers);
    
    // 必包含：错题向量（纠错）
    wrongVectors.forEach(v => {
      questions.push({
        ...generateQuestionForVector(card, v),
        roundInfo: { cardIndex: cardIdx, totalCards: selectedCards.length, cardName: card.name }
      });
    });
    
    // 必包含：反向向量（交叉验证）
    const reverseVectors = getReverseVectors(wrongVectors);
    reverseVectors.forEach(v => {
      questions.push({
        ...generateQuestionForVector(card, v),
        roundInfo: { cardIndex: cardIdx, totalCards: selectedCards.length, cardName: card.name }
      });
    });
    
    // 可选：药组向量（关联学习）
    if (card.data.canonical.herbs.length > 0) {
      questions.push({
        ...generateQuestionForVector(card, '0→2'),
        roundInfo: { cardIndex: cardIdx, totalCards: selectedCards.length, cardName: card.name }
      });
    }
  });
  
  // 4. 截断到10题
  if (questions.length > 10) questions = questions.slice(0, 10);
  
  // 5. 交错：同一方的题相邻，不同方之间打散
  questions = interleaveByCard(questions);
  
  // 6. 设置考试状态
  state.exam.questions = questions;
  state.exam.current = 0;
  state.exam.answers = [];
  state.exam.mode = 'retrieval-round';
  
  // 7. 显示结构声明
  showToast(`再来一组：${questions.length} 题，来自 ${selectedCards.length} 个方，每个方 2-3 个向量`);
}
```

### 改动2：答题界面增加进度信息

**当前**：只显示「第 X 题」
**改为**：显示「第 3/8 题 · 第 1 个方：桂枝汤（3/3 向量）」+ 进度条

### 改动3：结果页按方分组显示

**当前**：按题号线性列出
**改为**：按方剂分组，显示每个方不同向量的对错，检测"不均衡掌握"

## 五、改动原因总结

| 问题 | 认知神经科学原因 | 改动方案 |
|---|---|---|
| 题型间无关联 | 海马体需要同一窗口内共同激活才能建立神经联结（Hebbian） | 同一方的不同向量在同一轮中相邻排列 |
| 无反向向量 | 0→1 和 1→0 激活不同神经通路，单向练习不完整 | 必包含反向向量（答错0→1 → 给1→0） |
| 无明确题量 | 目标不确定性→焦虑→前额叶资源占用 | 结构声明：「8题，3个方，每方2-3向量」 |
| 无进度感 | 缺乏完成感→多巴胺不足→动机下降 | 进度条 + 实时计数 |
| 无关联提示 | 用户不知道上一题和这一题的关系 | 提示语：「上一题你刚确认了...」 |
| 无不均衡检测 | 用户可能某个方部分会部分不会 | 结果页检测"同一方不同向量对错不一致" |

## 六、一句话总结

> **再来一组不是"把错题重做一遍"，而是"把薄弱方从多个维度同时点亮，在短时记忆窗口内建立完整的方剂概念网络"。**
