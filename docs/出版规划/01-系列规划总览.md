## 一、系列总定位

**系列名**：《经方学习系统》  
**英文工作名**（预留）：*The Formula Learning System*  
**总精神**：一个中医学习者，用工程思维、学习科学和AI协作，构建个人知识系统的方法论实录。

**读者分层**（同心圆结构）：
- **核心圆**：中医学习者（最大体量，最需要）
- **第二环**：知识工程师 / 终身学习者（跨领域迁移）
- **第三环**：AI协作者 / 系统设计者（人机协作治理）

**跨领域迁移设计**：每一章末尾加一段"这个方法用在其他领域会怎样"，比如：
- 清洗策略 → 法律文书的格式标准化
- 质量评估 → 科研文献的筛选
- 卡片生命周期 → 论文写作的卡片笔记法

### 配套工具书：《经方学习系统 v8 速查手册》

**定位**：不是"读"的书，是"用"的书。放在诊桌或书包里。

**内容**：
- 太阳病36方卡片速查（一页一方，含原文/症状/药物/禁忌）
- 类方对比表（桂枝汤 vs 麻黄汤 vs 葛根汤，etc.）
- 八向量训练模板（空白，可复印）
- 临床记录模板（来自 `clinical/YYYY-MM-DD-template`）
- 剂量换算速查表（四标准对照）
- 核心药物组合速记（35方的核心药对）

**来源**：直接从 `data/formula_cards.json` 和 `data/source_cards.json` 导出。

### 番外特刊：《桂枝类方与神经科学》

**定位**：跨学科探索，不作为系列必读，作为"惊喜延伸"。

**内容**：直接以 `docs/桂枝类方与脑科学.md` 为底稿扩展。

**潜在合作**：如果找到神经科学或中医医史文献的专家审校，可以往学术期刊方向投稿，同时出版科普版本。

## 四、系列内部逻辑关系

```
第一卷 ────────┐
  │            │
  │ 引用       │  所有卷共享"中医学习"这个叙事底色
  ▼            │
第二卷 ────────┤
  │            │
  │ 引用       │
  ▼            │
第三卷 ────────┘

速查手册 ←── 从三卷的方法论中提炼出"即用即查"的工具
    ↑
番外特刊 ←── 从第一卷的双轨制出发，探索更深层的科学解释
```

**关键设计**：每卷末尾有一章"桥梁"——
- 第一卷结尾："这些卡片是怎么从原始材料中炼出来的？请看第二卷"
- 第二卷结尾："这些提取出来的卡片，是怎么被AI协作维护的？请看第三卷"
- 第三卷结尾："这套治理体系，最初是为了服务一个临床学习者的记忆训练。故事从第一卷开始。"

## 五、出版路线图

| 阶段 | 时间 | 动作 | 理由 |
|------|------|------|------|
| **Phase 0** | 现在 | 确定系列结构，选定第一卷试写章节 | 必须先验证"第一卷能不能写成" |
| **Phase 1** | 1-2个月 | 试写第一卷第3-4章（八向量 + 症状三分法） | 这两章最成熟、最独特，能检验读者接受度 |
| **Phase 2** | 3-4个月 | 完成第一卷全稿 | 最大市场，先占位 |
| **Phase 3** | 同期 | 启动速查手册的内容整理 | 可以作为第一卷的预售赠品或捆绑销售 |
| **Phase 4** | 第5-8个月 | 第二卷全稿 | 知识管理领域读者跟进 |
| **Phase 5** | 第9-12个月 | 第三卷全稿 | 更小众但更高客单价 |
| **Phase 6** | 持续 | 番外特刊作为"彩蛋"推出 | 依赖外部合作资源 |

## 六、各卷素材缺口与补充策略

| 卷 | 已有素材占比 | 需补充内容 | 难度 | 补充方式 |
|----|------------|-----------|------|----------|
| 第一卷 | 70% | 你的个人叙事（临床前夜、第一次实战、顿悟时刻） | ⭐⭐⭐⭐ | 口述历史录音 |
| 第二卷 | 80% | 跨领域迁移案例（非中医读者的类比） | ⭐⭐⭐ | 我可以辅助撰写 |
| 第三卷 | 85% | 人与AI协作的"情感线"（信任、冲突、磨合） | ⭐⭐⭐⭐ | 需要你把协作过程显式化 |

**最紧急的缺口**：第一卷的个人叙事。你现在有流程文档，但缺少"人的故事"。

**建议的口述历史主题**：
1. 你为什么开始学中医？（职业背景）
2. 第一个让你崩溃的bug或设计失败是什么？
3. DeepSeek评审"基本不可行"时，你的真实反应？
4. 第一次义诊回来，最想改系统的哪个功能？
5. 某个深夜改代码，发现备份没了的恐慌
6. 从"AI帮我写"到"AI是我的协作者"的心态转变

## 七、Branding 建议

- 每卷封面有相同的色系（中医传统色：赭石、黛青、朱砂）
