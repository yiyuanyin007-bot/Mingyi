**每卡产出标准**：
- `references.source_annotations` 数组，包含至少 1 个对象
- 每个对象包含：`text`（原文+标注）、`annotations`（刘渡舟/胡希恕/个人总结）
- 支持 slidePanel 新格式（`text` + `annotations` 对象，含 `刘渡舟`/`胡希恕`/`个人总结` 键）
- 200字摘要（summary）内嵌于 text 中

**执行步骤**（每卡）：
1. 备份 `data/formula_cards.json`
2. 读取本地资料，提取条文原文和注家讲解
3. 按 v2 格式生成 `source_annotations`
4. 验证 JSON 语法
5. 登记 CHANGELOG
6. 汇报完成

### Phase 4：P3 前端优化（分级解锁）

**目标**：实现条文内容的分级解锁——低掌握度只显示原文，高掌握度解锁注家讲解。

**设计要点**：
- 依赖卡片 mastery 向量（0→1、1→0）的等级
- 等级 0-1：只显示【条文】标签
- 等级 2-3：解锁【刘渡舟】标签
- 等级 4-5：解锁【胡希恕】标签
- 等级 6+：解锁【对比】和【我的理解】

**执行步骤**：
1. 修改 `normalizeSourceAnnotations` 增加过滤逻辑
2. 修改 slidePanel 标签渲染，根据等级显示/隐藏
3. 增加解锁提示（"达到等级 X 解锁此内容"）
4. 备份 + 浏览器验证 + 登记 CHANGELOG
