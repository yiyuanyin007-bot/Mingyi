# 经方学习系统 · 视觉设计规范 V1

> **适用范围**：所有前端页面、参考资料区、弹窗、卡片、标签  
> **设计原则**：信息层级清晰、阅读不累、临床感、可点击元素可识别

---

## 一、CSS 变量体系（已存在，全部使用）

```css
:root {
  --bg-body: #fafafa;      /* 页面背景 */
  --bg-panel: #ffffff;      /* 卡片/面板背景 */
  --bg-card: #f5f5f5;       /* 内部区块背景 */
  --bg-hover: #eeeeee;      /* 悬停背景 */
  --border: #e0e0e0;        /* 边框 */
  --text-primary: #212121;   /* 主文字 */
  --text-secondary: #616161; /* 次要文字 */
  --text-muted: #9e9e9e;     /* 弱化文字 */
  --accent: #455a64;         /* 主题色（蓝灰） */
  --accent-bg: #eceff1;      /* 主题色浅背景 */
  --success: #2e7d32;        /* 成功/疗效 */
  --error: #c62828;          /* 错误/禁忌 */
  --shadow: 0 1px 2px rgba(0,0,0,0.06);
}
```

**规则**：所有新增样式必须使用上述变量，禁止写死颜色。确保 dark/light 主题自动切换。

## 二、药物呈现规范（核心）

### 2.1 处方中的单味药

```html
<span class="rx-herb-name" onclick="onHerbClick('柴胡','da-chai-hu-tang')">柴胡</span>
<span class="rx-herb-dose">12克</span>
<span class="rx-separator">、</span>
```

| 元素 | 类名 | 样式 | 交互 |
|------|------|------|------|
| 药名 | `.rx-herb-name` | font-weight: 700; color: var(--text-primary); border-bottom: 1px dashed var(--accent); | 悬停：背景变 accent-bg，下划线变实线；点击：弹窗 |
| 剂量 | `.rx-herb-dose` | font-size: 12px; color: var(--text-muted); | 无交互 |
| 分隔 | `.rx-separator` | color: var(--text-muted); margin: 0 4px; | 无交互 |

### 2.2 合方标签

```html
<span class="rx-formula-tag" onclick="onFormulaClick('桂枝茯苓丸','gui-zhi-fu-ling-wan','da-chai-hu-tang')">
  <span class="rx-formula-label">合</span>桂枝茯苓丸
</span>
```

| 元素 | 类名 | 样式 | 交互 |
|------|------|------|------|
| 标签整体 | `.rx-formula-tag` | 12px, 600, accent色, accent-bg背景, 6px圆角, 1px边框 | 悬停：背景变accent，文字变白 |
| 前缀 | `.rx-formula-label` | 10px, muted色, 右侧4px间距 | 悬停时跟随父元素变白 |

**前缀规则**：
- "合" = 合方（如 合桂枝茯苓丸）
- "加" = 加味（如 加黄连）
- "减" = 减味（如 减大黄）
- "另" = 另加（如 另：排痰散）

### 2.3 处方整体容器

```html
<div class="ref-case-rx">
  <div class="ref-exp-formula-label">📋 处方</div>
  <!-- 药名+剂量+分隔 连续排列 -->
</div>
```

- 背景：var(--bg-body)
- 左边框：3px solid var(--success)
- 圆角：6px
- 内边距：10px 12px
- 行高：1.8（确保剂量小字不拥挤）

## 三、信息层级规范

### 3.1 卡片结构（从外到内）

| 层级 | 容器 | 背景 | 边框 | 圆角 | 用途 |
|------|------|------|------|------|------|
| 1 | `.section` | --bg-panel | 1px solid --border | 10px | 整个区块（如"临床医案"） |
| 2 | `.ref-exp-card` | --bg-panel | 1px solid --border | 10px | 单条经验/单条医案 |
| 3 | `.ref-case-card` | --bg-card | 1px dashed --border | 8px | 医案内部的子卡片（患者画像） |
| 4 | `.ref-case-rx` | --bg-body | 左边框3px | 6px | 处方框 |
| 4 | `.ref-case-outcome` | --bg-body | 左边框3px | 6px | 疗效框 |

### 3.2 文字层级

| 层级 | 大小 | 粗细 | 颜色 | 用途 |
|------|------|------|------|------|
| 标题 | 15px | 700 | --text-primary | 医案标题、经验标题 |
| 正文 | 14px | 400 | --text-primary | 症状描述、摘要 |
| 元信息 | 12px | 400 | --text-secondary | 作者、来源、日期 |
| 标签 | 11px | 400 | --text-secondary | 患者标签、症状标签 |
| 剂量 | 12px | 400 | --text-muted | 药物剂量 |
| 前缀 | 10px | 400 | --text-muted | "合"/"加"前缀 |

## 四、交互规范

### 4.1 可点击元素

| 元素 | 点击前 | 悬停 | 点击后 |
|------|--------|------|--------|
| 药名 | 下划线虚线 | 背景变浅，下划线实线 | 弹窗显示关联方 |
| 合方标签 | 灰底彩字 | 彩底白字 | 弹窗显示方简介 |
| 参考链接 | 带色文字 | 背景变浅 | 新标签页打开 |
| 查看原文 | 带边框按钮 | 背景变浅 | 打开文件/URL |

### 4.2 弹窗规范

- 遮罩：rgba(0,0,0,0.5)
- 弹窗：--bg-panel, 12px圆角, 1px边框
- 最大宽度：480px
- 最大高度：80vh
- 关闭：点击遮罩、点击关闭按钮、按ESC

## 五、状态标识

| 状态 | 样式 | 用途 |
|------|------|------|
| 链接可用 | 正常颜色 | 本地文件存在或URL有效 |
| 链接失效 | 文字删除线 + 灰色 | URL 404或文件不存在 |
| 已掌握 | 绿色圆点 | 向量掌握度达标 |
| 学习中 | 灰色圆点 | 向量正在学习 |

- [ ] 分隔符使用 `.rx-separator` 类
