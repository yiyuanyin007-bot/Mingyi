总结 — 修改了什么？
去掉冗余 把 4 套笔记（卡片笔记/我的理解/记笔记按钮/错题本笔记）合并为「条文笔记」一套，所有笔记都附着于条文。
合并入口 条文面板中「我的理解」标签页 + 「记笔记」按钮合并为：每条条文正文下方的一个可展开/收起的笔记区。
零摩擦保存 支持 Ctrl+Enter 保存 + 显式保存按钮，输入时无需切换标签页。
笔记预览 条文列表中，有条文的条目显示笔记摘要，学习时一眼看到自己写过什么。
可选结构化 支持标签（病机/鉴别/方证/疑问），但不强制。

核心原则

笔记是条文的延伸，不是独立的知识点。

读原文 → 产生理解 → 原地记录 → 下次复习时看到。
