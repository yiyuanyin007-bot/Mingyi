# 诊断标签重设计方案 · 认知神经科学与学习科学版

> 目标：将"搞混了/记错了/没学过/乱选的"四个模糊标签，升级为基于认知神经科学的精准错误分类体系，每个标签都指向具体的神经机制和对应的学习干预策略。

---

## 一、当前四标签的认知缺陷分析

### 1.1 「搞混了」—— 语义模糊，无法指导后续学习

**问题**：
- 用户选了麻黄汤（正确答案应该是桂枝汤），点"搞混了"。
- 系统知道"搞混了"，但不知道：是**两个方搞混**了？还是**症状和方名**搞混了？还是**药组搞混**了？
- 结果：后续生成Prompt时，只能泛泛地写"两方对比"，无法精准打击。

**神经科学视角**：
- 海马体中，桂枝汤和麻黄汤的**神经元表征有重叠**（都是解表剂、都治太阳病）。
- 当用户只练了 0→1（方名→症状），但没有练 1→0（症状→方名）时，这两个概念的**区分性特征**（necessary features）没有被强化。
- "搞混了"这个标签没有捕捉到"搞混的方向"和"搞混的维度"，导致系统无法生成针对性的对比Prompt。

---

### 1.2 「记错了」—— 表层归因，掩盖真实问题

**问题**：
- "记错了"暗示"我曾经记得，现在记错了"。
- 但实际情况可能是：
  - 用户**根本就没记住**（编码失败）
  - 用户记住了但**提取通路不通**（知道方名→症状，但症状→方名走不通）
  - 用户记住了**错误的关联**（错误信息被编码了）
- 结果：系统给出一个"记忆口诀"，但如果是提取通路问题，口诀没用。

**神经科学视角**：
- 记忆不是单一的"存储-提取"过程，而是**编码 → 巩固 → 提取 → 再巩固**的循环。
- "记错了"可能对应三种完全不同的神经状态：
  1. **编码错误**：错误信息被写入了突触权重（如"桂枝汤治无汗"被错误编码）
  2. **提取失败**：正确信息在记忆中，但提取线索不足（如只看到"汗出"但没有"恶风"的提示）
  3. **干扰**：先验知识（proactive interference）干扰了当前提取（如先学了麻黄汤，干扰了桂枝汤的记忆）
- 这三种状态需要完全不同的干预策略。

---

### 1.3 「没学过」—— 推卸性归因，不利于学习

**问题**：
- "没学过"暗示"这不是我的问题，是内容没教过"。
- 在中医学习中，"没学过"往往不是真的没看过，而是：
  - 看过但**没注意到**（注意选择失败）
  - 学过但**没理解**（深度加工不足）
  - 学过但**没和已有知识建立关联**（意义建构失败）
- 结果：用户点"没学过"后，系统可能给出一个完整的入门介绍，但用户可能只需要一个**关键区分点**。

**神经科学视角**：
- 注意系统的**选择性过滤**：大脑不会无差别地接收所有信息，而是根据**先验预期**过滤。
- 如果用户学桂枝汤时，大脑预期"这就是个解表剂，和麻黄汤差不多"，那么"桂枝汤调和营卫"这个关键区分特征会被**过滤掉**，导致"没学过"的错觉。
- 这不是"没学过"，而是"**没注意到**"（inattentional blindness）。

---

### 1.4 「乱选的」—— 无信息量，不指向任何改进

**问题**：
- "乱选的"是最无用的标签，它告诉系统"用户没有认真思考"。
- 但系统不能据此生成任何有效的学习干预。
- 结果：用户点"乱选的"后，系统只能泛泛地说"下次认真审题"，这没有任何学习价值。

**神经科学视角**：
- "乱选"背后可能有多种神经机制：
  1. **前额叶抑制控制失败**：看到"汗出"就选桂枝汤，没有进一步检查"恶风"和"脉浮缓"
  2. **工作记忆溢出**：题干太长，工作记忆无法维持所有信息，导致信息丢失后乱选
  3. **时间压力**：快速答题模式导致系统1（直觉）压倒了系统2（理性）
  4. **动机下降**：用户觉得"反正不会，随便选一个"
- 这四种状态需要完全不同的界面设计和反馈策略。

## 二、新设计：基于认知神经科学的四维错误分类

### 核心原则：每个标签 = 一个认知状态 + 一个神经机制 + 一个学习干预

```
┌─────────────────────────────────────────────────────────────┐
│  新标签体系                                                   │
│                                                             │
│  1. 类方混淆  ← 概念干扰（海马体表征重叠）                   │
│  2. 反向盲区  ← 提取通路不对称（单向编码）                   │
│  3. 知识缺口  ← 编码/注意失败（信息未进入长时记忆）         │
│  4. 决策失误  ← 执行控制失败（前额叶抑制控制不足）         │
│                                                             │
│  每个标签点完后 → 静默保存 + 精准Prompt生成                │
└─────────────────────────────────────────────────────────────┘
```

---

### 标签1：「类方混淆」🔀（替代「搞混了」）

**定义**：把两个**结构相似**的方搞混了（如桂枝汤 vs 麻黄汤，都是解表剂，但一个治中风一个治伤寒）。

**神经机制**：**概念干扰（Conceptual Interference）**
- 海马体中，相似概念的神经元表征有**重叠**。
- 当提取线索（如"汗出、恶风"）同时激活两个概念的神经元群体时，大脑无法区分哪个是"正确目标"。
- 这类似于 Rescorla-Wagner 模型中的**竞争学习**：两个概念在争夺同一组提取线索的权重。

**识别信号**：
- 用户选了一个**和正确答案同类别**的干扰项（如桂枝汤和麻黄汤都是太阳病解表剂）
- 用户选了一个**同一基方**的变方（如桂枝加葛根汤 vs 桂枝汤）
- 系统可以通过 `generateOptions` 的干扰项分析来**自动识别**：如果用户选的是 top-3 相似卡片中的某一个，自动标记为「类方混淆」

**学习干预**：
1. **生成对比表Prompt**：
   ```
   你刚才把【桂枝汤】和【麻黄汤】搞混了。
   请用对比表说明两方的核心差异：
   | 维度 | 桂枝汤 | 麻黄汤 |
   |---|---|---|
   | 病机 | 营卫不和 | 表实闭郁 |
   | 必要症 | 汗出、恶风 | 无汗、脉浮紧 |
   | 核心药 | 桂枝+芍药 | 麻黄+桂枝 |
   | 一句话 | 有汗用桂枝，无汗用麻黄 |
   ```
2. **后续出题策略**：
   - 再来一组时，**强制将这两个方放在同一轮**（对比学习）
   - 生成**区分性特征题**（如"以下哪项是桂枝汤有但麻黄汤没有的？"）

**界面设计**：
```
🔀 类方混淆
   把相似的两个方搞混了（如桂枝汤↔麻黄汤）
```

---

### 标签2：「反向盲区」↔️（替代「记错了」）

**定义**：**正向会，反向不会**。比如看方名知道症状，但看到症状想不起来方名。或者知道药组，但不知道这个药组对应哪个方。

**神经机制**：**提取通路不对称（Asymmetric Retrieval Pathways）**
- 大脑中，0→1（方名→症状）和 1→0（症状→方名）是**两条独立的神经通路**。
- 如果用户只练了 0→1，那么 1→0 的通路是**未被髓鞘化**的（未强化），提取时需要更多的神经激活才能达到阈值。
- 这类似于 McClelland 的互补学习系统：海马体负责快速学习，但只有通过**多方向提取**，知识才能从海马体转移到皮层形成稳定表征。

**识别信号**：
- 用户上一轮同一方**0→1 对了，但 1→0 错了**
- 或者用户选了正确答案，但用了很长时间（说明提取困难）
- 系统可以通过**历史答题模式**自动识别：如果某方 0→1 正确率高但 1→0 正确率低，自动标记为「反向盲区」

**学习干预**：
1. **生成反向练习Prompt**：
   ```
   你刚才在「症状→方名」的提取上有困难。
   请用以下方法强化反向通路：
   1. 遮住方名，只看症状，问自己"这是哪个方？"
   2. 用临床场景联想：「看到汗出恶风，第一反应是...」
   3. 口诀：汗出恶风桂枝汤，无汗恶寒麻黄汤
   ```
2. **后续出题策略**：
   - 再来一组时，**增加该方的 1→0 题比例**
   - 生成**变方干扰题**（如「汗出恶风+项背强几几 → 选桂枝加葛根汤而非桂枝汤」）

**界面设计**：
```
↔️ 反向盲区
   正向会，反向想不起来（如知道方名→说不出症状）
```

---

### 标签3：「知识缺口」🕳️（替代「没学过」）

**定义**：这个方或这个向量**从未真正进入长期记忆**。不是"没学过"，而是"学过但编码失败了"。

**神经机制**：**编码失败 / 深度加工不足（Shallow Processing）**
- Craik & Lockhart (1972) 的深度加工理论：信息只有经过**语义层面的加工**（如"这个方治什么病"），才能进入长时记忆。
- 如果只是**浅层加工**（如"这个方有5味药"），信息不会进入长时记忆，表现为"完全没印象"。
- 另外，**注意选择失败**也会导致编码失败：如果学的时候大脑预期"这个方和之前的差不多"，关键区分特征会被过滤。

**识别信号**：
- 用户在这个方/向量的**首次答题**就错了
- 用户在这个方/向量上的**历史正确率极低**（< 20%）
- 用户选了**完全无关**的干扰项（如把桂枝汤选成小柴胡汤，两者没有结构相似性）

**学习干预**：
1. **生成深度加工Prompt**：
   ```
   这个知识点似乎没有进入你的长期记忆。
   请用以下方法重新编码：
   1. 一句话定位：这个方是治什么的？（一句话）
   2. 核心症状：必须见到的症状是什么？（3个以内）
   3. 核心药组：方根药是什么？（2-3味）
   4. 临床场景：在什么情况下你会想到开这个方？
   5. 个人联想：把这个方和一个你熟悉的场景/人物联系起来
   ```
2. **后续出题策略**：
   - 再来一组时，**优先覆盖这个方**
   - 降低难度（选项更差异化，给更多提示）
   - 增加**提示性题目**（如「这个方治太阳中风，必要症状是？」）

**界面设计**：
```
🕳️ 知识缺口
   这个方/向量没进脑子，需要重新编码
```

---

### 标签4：「决策失误」🧠（替代「乱选的」）

**定义**：**知道答案但选错了**，或**没看完题就选了**。这不是"不会"，而是"没想好"。

**神经机制**：**执行控制失败（Executive Control Failure）**
- Kahneman 的系统1（快速直觉）压倒了系统2（缓慢理性）。
- 前额叶皮层（负责抑制控制和工作记忆）**没有充分参与**，导致看到关键词就冲动选择。
- 也可能是**工作记忆溢出**：题干包含多个症状，工作记忆无法同时维持，导致信息丢失后基于不完整信息选择。

**识别信号**：
- 用户选了**部分正确但不够完整**的答案（如看到"汗出"就选桂枝汤，但没看到"恶风"）
- 用户答题**时间极短**（< 3秒，说明没有深思熟虑）
- 用户在**多选题**中漏选了必要条件
- 用户选了**语法相似但语义不同**的选项（如"桂枝汤"和"桂枝加葛根汤"）

**学习干预**：
1. **生成审题策略Prompt**：
   ```
   你刚才可能是冲动选择，没有完全审题。
   请用「三步审题法」：
   1. 停：看到题目后，先停3秒，不要立刻选
   2. 全：列出所有关键词（症状、脉象、病机）
   3. 对：逐一核对每个必要条件，确保全部满足
   
   临床中也是一样：先看全、再想、再开方。
   ```
2. **后续出题策略**：
   - 增加**复杂病例题**（多症状组合，需要系统分析）
   - 增加**时间限制**（适度压力训练执行控制）
   - 答题界面增加**提示**：「先列出所有症状，再选方」

**界面设计**：
```
🧠 决策失误
   知道但不会选，需要训练审题策略
```

## 三、自动识别系统：减少用户认知负担

用户不需要每次都手动选标签，系统可以**基于答题模式自动推荐**默认标签。

### 自动识别规则

| 条件 | 自动推荐标签 | 原理 |
|---|---|---|
| 干扰项是 top-3 相似卡片 | 「类方混淆」 | 概念表征重叠 |
| 同一方正向对、反向错 | 「反向盲区」 | 提取通路不对称 |
| 历史正确率 < 20% | 「知识缺口」 | 编码失败 |
| 答题时间 < 3秒 | 「决策失误」 | 执行控制不足 |
| 选了完全无关的方 | 「知识缺口」 | 无概念表征 |
| 多选题漏选必要条件 | 「决策失误」 | 工作记忆溢出 |

### 交互设计：推荐 + 用户确认

```
┌─────────────────────────────────────────┐
│  这题为什么错了？（系统已推荐）            │
│                                         │
│  [推荐] 🔀 类方混淆 ← 你选了麻黄汤        │
│  [备选] ↔️ 反向盲区                      │
│  [备选] 🕳️ 知识缺口                      │
│  [备选] 🧠 决策失误                      │
│                                         │
│  [确认并保存] [换一个标签]                │
└─────────────────────────────────────────┘
```

**好处**：
- 减少用户选择认知负荷（有推荐）
- 但保留用户自主权（可以换）
- 系统通过推荐质量学习用户模式，越用越准

## 四、标签与后续学习的闭环

每个标签不仅影响 Prompt 生成，还影响**后续学习策略**：

| 标签 | 错题本标记 | 再来一组策略 | 复习间隔 |
|---|---|---|---|
| 类方混淆 | 关联该方和混淆方 | 将两方放在同一轮对比 | 缩短（需要频繁对比） |
| 反向盲区 | 标记薄弱向量 | 增加反向向量题比例 | 正常 |
| 知识缺口 | 标记为新学内容 | 优先覆盖，降低难度 | 极短（每天复习） |
| 决策失误 | 标记为策略问题 | 增加复杂病例题 | 正常 |

## 五、界面重新设计

### 当前界面（问题）

```
[🤔 搞混了] [😵 记错了] [❓ 没学过] [😫 乱选的]
```

问题：
1. 表情符号和标签语义无关（😵 记错了？为什么是😵？）
2. 标签之间没有区分度
3. 没有提示用户"为什么选这个标签"

### 新界面

```
┌────────────────────────────────────────────┐
│  这题为什么错了？（选一个最符合的）           │
│                                             │
│  🔀 类方混淆                                │
│     和相似方搞混了（如桂枝汤↔麻黄汤）       │
│                                             │
│  ↔️ 反向盲区                                │
│     正向会，反向想不起来                     │
│                                             │
│  🕳️ 知识缺口                                │
│     这个知识点没进脑子，需要重新学           │
│                                             │
│  🧠 决策失误                                │
│     知道但不会选，需要训练审题               │
│                                             │
│  [系统推荐：🔀 类方混淆] [确认]             │
└────────────────────────────────────────────┘
```

**设计要点**：
1. 每个标签有**图标**（不是表情，而是语义符号）
2. 每个标签有**副标题**解释含义
3. 系统**推荐**默认标签，减少用户选择负担
4. 用户确认后**静默保存**（不打断心流）

## 六、认知神经科学理论总结

| 标签 | 神经机制 | 关键理论 | 研究者 |
|---|---|---|---|
| 类方混淆 | 概念表征重叠，竞争学习 | Rescorla-Wagner 竞争学习 | Rescorla & Wagner (1972) |
| 反向盲区 | 提取通路不对称，海马体→皮层转移 | 互补学习系统理论 | McClelland et al. (1995) |
| 知识缺口 | 编码失败，浅层加工 | 深度加工理论 | Craik & Lockhart (1972) |
| 决策失误 | 执行控制失败，系统1压倒系统2 | 双系统理论 | Kahneman (2011) |

## 八、一句话总结
